# 暂停地图的截图背景

## 触发与边界

需要让可交互 3D 地图看起来覆盖在游戏画面上，但不希望依赖游戏相机与地图相机堆叠时使用。这里用一次捕获的图像替代背景游戏视图；地图开启期间世界必须冻结。需要背景继续模拟、动画或反映多人世界变化时，不采用本入口，另选实时合成方案。

## 输入与前置条件

- 既有暂停/输入归属接口、游戏视图与地图呈现入口；明确哪些模拟、角色输入、游戏相机及独立时钟效果必须冻结。不能只设置时间缩放就假定整个世界已停。
- 捕获来源及引擎可用的完成通知：需要哪一帧、哪台相机/视口、是否包含游戏 HUD、是否包含后处理。地图、菜单入场遮罩及截图平面本身必须排除。
- 地图相机的投影与有效 viewport、地图几何深度范围、背景平面的单位尺寸与朝向；区分窗口尺寸、动态渲染分辨率与实际输出画幅。
- 捕获格式、分辨率、颜色空间/HDR 映射及纹理所有权；确定尺寸改变时保全图留边还是等比铺满裁切，以及捕获失败时取消打开或使用明确的纯色回退。
- 地图输入、旋转/缩放和 UI 动画使用暂停后仍工作的更新路径。若无法冻结世界又保持地图可操作，先修暂停契约，不交付静态截图冒充实时背景。

## 实施步骤

1. 建立 Closed → Capturing → Open → Closed 生命周期，保存会话编号、暂停令牌、输入/相机归属、纹理句柄、捕获尺寸与就绪状态。重复打开不叠加暂停或捕获；任意阶段的关闭都进入同一清理路径。
2. 打开时先接管地图输入并阻止角色动作，取得本会话的暂停令牌，在一致的世界/相机状态下准备捕获。此时地图及截图平面仍隐藏。让渲染提交继续运行，等待指定游戏视图的干净帧及 GPU 复制完成，不等待已经停掉的游戏计时器。若项目使用最近已完成帧，必须验证它属于当前视口、场景和约定冻结时刻，不能随意复用上一帧或旧地图会话。
3. 在选定的渲染阶段把游戏视图复制到本会话可持有的纹理；不能只引用下一帧会被覆盖的临时目标。捕获回调先核对会话仍有效、场景和尺寸一致，再发布纹理。捕获期间关闭或重开后到达的旧回调，只按资源所有权回收，不能重新打开地图。失败则执行已选回退，不展示上次地点的截图。
4. 将纹理绑定到地图后方的平面，用保持截图颜色的材质与合成路径；检查 UV 上下方向、sRGB/线性转换、HDR 与色调映射，避免截图经过同一处理两遍。平面不参与世界碰撞、拾取、光照或投影阴影；以专用层/材质控制呈现，不全局关闭地图深度关系。确认地图几何位于背景前且都在相机裁剪范围内，再显示地图并进入 Open。
5. 让平面跟随地图相机的视图平面，而非跟随可旋转的地图模型；地图相机环绕/缩放时重新保持背景的屏幕位置与覆盖。尺寸、距离和投影参数必须有限且有效；d 为正，垂直 FOV 在 0 与 180 度之间。标准对称透视相机在距离 d 处的视口高度为 2d·tan(垂直 FOV/2)，宽度为高度乘 viewport 宽高比；正交相机取实际可见高度。按网格本身尺寸换算缩放，选择 d 时确保在地图后方且不越过远裁剪面。非对称投影或镜头偏移用视锥角点在目标平面上的交点求矩形，不套中心对称公式。
6. 分开处理平面覆盖与图像比例。截图比例等于 viewport 时完整铺满；不相等时，按输入约定等比 contain 加底色或 cover 裁切，用 UV/图像区域实现，不把截图横向拉伸。窗口、viewport 或相机投影变化时，重算平面、UV 和留边，继续使用原始冻结截图，不从已经显示地图的最终帧重新截图。原图没有的新视野不能凭缩放补出；画幅变化不可接受时关闭后按干净捕获流程重开，而不是捕获地图套地图。
7. Open 期间只更新地图及允许的 UI；截图保持不变。房间焦点、环绕与缩放由[房间地图导航](../gameplay-room-map-navigation/SKILL.md)负责；焦点/可用状态显示复用[交互状态反馈](../gameplay-contextual-ui/SKILL.md)。暂停所有权与地图输入归属只能由一个协调者取得和释放，不能让这些组合流程各自无条件恢复世界。
8. 关闭、切场、捕获失败或呈现控制权丢失时，先使会话失效并停用地图输入，隐藏地图/背景，解绑纹理与监听，再释放或按已定策略归还捕获资源。尚在 GPU 使用的资源延迟到安全点回收。只释放自己的暂停令牌与控制权；其他菜单仍持有暂停时不能恢复世界，不用固定 timeScale=1 覆盖原状态。下一次打开必须有当前场景的新捕获，不以保留纹理句柄代表图像仍有效。

## 调参与故障定位

先校捕获时机及包含内容，再校颜色与画幅，最后按目标平台测量捕获分辨率、过滤、内存和开图延迟。降低分辨率是质量/成本选择，不应改变图像比例或地图坐标。

- 背景出现地图、遮罩或递归缩图：检查捕获阶段与显示顺序，保持地图隐藏直到捕获完成；不要靠延迟若干固定毫秒掩盖顺序问题。
- 背景变黑或卡在打开：检查暂停后渲染/回调是否仍运行、复制完成条件、临时目标寿命和格式支持，失败时可退出并释放暂停。
- 背景旋转、露边或压住地图：检查平面是否误挂到地图模型、投影/viewport 是否混用及深度范围；不要修改房间导航来补背景错误。
- 背景偏亮、偏暗或高光截断：查捕获是 HDR 还是已映射输出、读写颜色空间和第二次后处理，不能以统一乘亮度当通用修复。
- 重开闪旧场景或内存持续上涨：记录会话、捕获帧、纹理所有者及异步释放；失效回调不发布，不能只在正常关闭时清理。

## 验收

- [ ] 打开瞬间的背景与约定冻结游戏帧一致，包含内容符合 HUD 策略；没有地图、入场遮罩或上一会话残影。
- [ ] 地图开启后世界与游戏相机不继续变化，地图操作和必要 UI 仍响应；地图旋转/缩放不拖动背景，背景始终位于几何后方。
- [ ] 标准宽屏、超宽及项目目标画幅下图像不被拉伸；打开期间 resize/投影变化执行所选裁切或留边策略，不重捕获地图，也不承诺不存在的边缘视野。
- [ ] 快速打开→关闭→重开、捕获中取消、切场及捕获失败均无陈旧回调复活、卡死暂停或错误恢复；嵌套菜单关闭不释放别人的暂停。
- [ ] 多次开关后纹理资源回到约定的释放/池化基线，GPU 未完成使用时不会提前释放；颜色、延迟和内存结果以项目实际渲染配置验证。

本入口与[固定视角插画投影](../gameplay-fixed-camera-art-projection/SKILL.md)不同：这里捕获运行时冻结帧作为屏幕背景，不制作可参与场景遮挡的插画环境资产。需要核查来源、作者兼容性问题及工程推导边界时，读取[来源参考](references/sources.md)。

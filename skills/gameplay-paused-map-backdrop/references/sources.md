## 支持的机制与未知项

支持：暂停世界时捕获游戏视图，将截图贴到地图背后平面，平面随相机画幅适配，前方地图仍可交互。世界必须冻结；背景不是持续更新的游戏视图。

未知：具体引擎/插件版本和完整渲染配置、捕获 API、暂停与捕获的精确顺序、捕获相对 HUD/后处理的阶段、GPU 完成通知、纹理格式和分辨率、HDR/gamma/色调映射、平面投影拟合公式、材质/层级与深度设置、异步取消、资源复用/销毁、resize 和恢复时序。不得把这些工程选择写成作者已展示的实现。

DLSS 与相机堆叠的失败只属于作者所述配置，不构成 Unity、DLSS 或任意渲染管线普遍不支持相机堆叠的结论。

## 本技能补充的工程方案

以下是为了可实施而补充的候选设计及待执行验收，不是作者代码、源视频实测或普遍默认值：

- Closed/Capturing/Open 生命周期、暂停令牌、单一协调者、输入归属与暂停后独立 UI 更新路径；明确世界、相机及独立时钟效果的冻结范围。
- 捕获前排除地图及遮罩、保留渲染提交、选择一致冻结帧、等待 GPU 完成、复制到可持有纹理及会话/场景校验。捕获 API 和渲染阶段需要项目自行选择。
- 标准透视视锥尺寸与正交可见尺寸用于平面拟合，非对称投影使用角点求交；背景平面对齐地图相机而不是旋转地图模型。距离、裁剪范围、材质与合成方案依项目确定。
- 将平面覆盖与图像等比 contain/cover 分开；resize 复用原始冻结截图，必要时关闭再按干净流程打开，禁止用已含地图的帧递归重捕获。原图缺失视野不可恢复。
- UV、颜色空间、HDR、色调映射及格式检查；纹理所有权、异步旧回调抑制、安全释放/池化、取消/切场清理与嵌套暂停释放。
- 快速重入、捕获失败、画幅改变、暂停期间地图操作、色彩一致性和资源基线验收；尚未在引擎运行，不提供性能提升或开图延迟的实测保证。

## Owner 边界与登记

- gameplay-paused-map-backdrop：运行时暂停地图的截图捕获、背景平面呈现/拟合和本次捕获生命周期。
- gameplay-room-map-navigation：房间选择、焦点、环绕/缩放与平滑聚焦。两者可组合，但不能各自无条件接管/恢复同一暂停或相机。
- gameplay-contextual-ui：焦点、可用和提交反馈，不拥有截图资源或世界冻结契约。
- gameplay-fixed-camera-art-projection：固定参考视角下把插画映射到场景简模，不是一次性游戏帧背景。

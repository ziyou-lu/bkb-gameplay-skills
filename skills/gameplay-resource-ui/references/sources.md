# 法力与体力的实时资源读数

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 资源消耗/耗尽没有明确确认，或成长徽章堆叠遮住攀爬体力读数。

## 先确认的输入

真实资源值/上限、消耗成功/失败、恢复/耗尽、成长信息与界面生命期。

## 分步机制

1. 区分真实值和显示动画，列出可用、消耗、耗尽和恢复状态；不足或取消不能播成功。
2. 法力宝石消耗可选闪光/碎裂，恢复可回弹/压缩；复用共享机制而非让动画结束决定资源到账。
3. 持续动作把实时体力读数收紧到角色附近的圆环/短条，与成长/收集徽章分层；这是来源对照引出的设计建议，非通用布局。
4. 检查真实消耗量与显示长度/分段关系。红色残留段和外缘小点不能擅自解释成固定公式或延迟血条；需要同一平滑/残影机制时引用血条 owner。

## 适用限制

- 法力宝石仅 UI 展示、中段字幕不全，资源逻辑未核；体力红段延迟/曲线、点数公式与声音未知。
- 紧凑布局不是所有场景更优的结论；没有已执行战斗资源代码或玩家量化测试。

## 验收

- [ ] 持续消耗、耗尽、恢复、上限/成长改变时显示对应真实量，且不被徽章堆叠遮挡。
- [ ] 不足/取消不显示成功，反复消费和关闭重开不重复扣资源或残留动画。
- [ ] 减少运动和低特效下仍能读出状态；显示不能误导可用操作。

## 组合而不复制

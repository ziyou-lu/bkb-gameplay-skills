# 法力与体力的实时资源读数

## 触发条件

法力/体力消耗、耗尽或恢复难读，成长徽章遮住实时读数。

## 输入与前置条件

真实值/上限、消费成功/失败、恢复/耗尽事件、成长信息和界面生命周期。

## 实施步骤

1. 将真实量与显示量分开，按当前值/上限生成读数；消费失败或取消不播成功碎裂。
2. 离散法力宝石可消费时闪光/碎裂、恢复时回弹；资源到账不依赖回弹结束。
3. 持续动作选择紧凑角色附近圆环/短条，与成长/收集徽章分层；两种布局按视距和遮挡比较，不要求所有资源都改圆环。
4. 明确分段、小点及残留条各表达什么量，不用装饰暗示未定义公式；需要数值平滑/损失残影时调用血条 owner。
5. 上限变化、重开和目标切换从权威量重新同步，清理旧动画；显示不得反向扣/加资源。

## 参数调整

调位置、尺寸、段数和恢复动效；消耗追不上显示时缩短平滑或保留即时真实值标记。成长层遮挡先改布局，不删实时状态。

## 验收与失败处理

- [ ] 持续消费、耗尽、恢复和上限改变正确；不足条件不显示成功。
- [ ] 连续消费/关闭重开不重复扣量或残留动画。
- [ ] 低特效/减少运动下可读可用量，冷却与按住进度不混同资源。

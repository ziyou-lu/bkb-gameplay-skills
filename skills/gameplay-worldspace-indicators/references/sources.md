# 世界内位置参照与操作指示

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。两分支共用“参照对象→位置含义→锚点/表面→视角校对”的检查流程，但操作目标与当前地面投影不是同一个点；按任务选择，不强制叠加。

## 触发条件

- 操作改为世界内表达后，目标圈在一个镜头重合、换视角却离开目标深度。
- 角色腾空时与地面分离难读，希望保留当前地面位置参照，而非预测未来着陆位置。

## 先确认的输入

实际参照对象的位置/深度、标记要表达的含义、相机投影、世界/UI 层级、锚点及存在状态。操作分支另需输入和真实成功事件；地面参照另需允许承接的表面、投影策略和无有效表面时的处理。后者实现未从来源公开，不默认射线、decal、投影器或 mesh。

## 分步机制

1. 先声明标记代表什么：实际可操作目标的位置，还是角色当前到地面的空间参照。分别核对参照对象和接收位置，不能因为画面重合就认定语义正确，也不能把阴影点当角色将来必定落到的点。
2. 固定相机与参照物，记录错位/深度难读，再改变观察角度验证。先校对空间关系，再加动画或材质，不为表现调整真实操作范围、跳跃轨迹或碰撞。

### 世界内操作目标

1. 从侧视与俯视检查目标环和真实目标深度关系。Dd9v8pMhc_t 展示二维量表改为世界内鱼影/涟漪目标，并明确深度对齐，但未给投影实现。
2. 对齐后再加鱼钩等指示动画及线条关系，不让运动遮盖真实目标或暗示尚未成立的成功。
3. 按项目现有输入/判定实现更新、取消和结果反馈；dynamic pull 仅据正文，不能反推算法或完整捕鱼输入规则。

### 腾空角色的当前地面参照

1. DP9AmTCj389 可见腾空角色下方地面软圆斑、落地时贴近脚下的斑，以及窄板上腾空角色下方黑椭圆。作者用它辅助跳跃/落地空间判断；这只是当前位置与接收面的参照，不是未来弹道落点或物理灯光准确性。
2. 采用此类标记时，明确当前参照位置和接收面选择，并检查角色升降/水平移动时标记的语义与锚点。来源未给投影方向、面选择或连续跟踪误差，不能补成已验证的“垂直射线命中地板”实现。
3. 分别检查边缘、斜坡、多层表面和无接收面情形，按项目处理隐藏、保持或其他回退，避免投射到无关/不可见表面后误导。大小/透明度随高度变化不是源帖已给功能；需要时独立验证。
4. 角色/表面消失、切场或状态改变后清理标记。若项目支持墙/天花板或可变重力，需要重新声明投影参照，不把本帖地面/窄板示例推广为已覆盖所有表面。

## 适用限制

- Dd9v8pMhc_t 只证明从二维量表到世界内目标及深度问题展示，没有完整捕鱼算法、输入参数或声音核听；地面阴影补证不能填补其 dynamic pull 缺口。
- DP9AmTCj389 是新效果展示与作者动机，没有旧新 A/B。开头“makes zero sense”是修辞，不是破损旧版证据；另插入的其他平台游戏参考镜头不能算作者实现。
- 地面/窄板上斑的位置在有限画面可见，未独立测连续跟踪精度、着陆命中率或高度判断。投影算法/方向、范围、表面过滤、遮挡、大小/透明度曲线、墙/顶面及重力变化处理未知，不宣称未来落点求解或性能收益。
- 两来源均未执行代码或核听音频。空间指示可见不等于操作成功、真实接地、可站立或可安全着陆；以下状态与表面验收是工程建议。

## 验收

- [ ] 先写明标记的空间含义，再在不同相机、目标深度/角色高度和屏幕比例下检查；真实目标标记和当前地面参照各自正确，不混淆为同一坐标。
- [ ] 操作分支对移动目标、取消和成功/失败及时更新/清理锚点、鱼线与动画；原输入范围和成功条件不变，有意规则修改单列验收。
- [ ] 地面参照分支覆盖角色上升/下落、水平移动、地面/窄板边缘、斜坡和多层表面；记录正确接收面和跟踪误差，不能把未测项写为来源成果。
- [ ] 无有效地面、被遮挡或超出项目范围时有明确策略，不穿过无关表面提供虚假的落点/支撑暗示；墙/顶面与重力改变若支持需另验。
- [ ] 角色/目标/表面销毁、传送和切场后不残留参照。实际测试深度/位置辨认，不以作者跳跃动机代替着陆提升结论，不修改轨迹或攀附判定。

## 组合而不复制

- [世界目标发现性](../../gameplay-world-readability/SKILL.md)解决“哪里有目标”，本页校对参照位置和空间含义。
- [交互状态](../../gameplay-contextual-ui/SKILL.md)仍由真实成功/失败事件驱动，不由标记接近决定。
- [重力方向线索](../../gameplay-gravity-orientation-cues/SKILL.md)只表达实际向下方向，地面参照还要明确位置和接收面。
- [落地反馈](../../gameplay-landing-feedback/SKILL.md)确认接触事件，不把持续参照圆斑当作已落地。
- [攀附支撑估计](../../gameplay-surface-adhesion/SKILL.md)影响角色附着位姿，不由显示标记反向决定物理支撑。

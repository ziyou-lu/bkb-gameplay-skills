# 交互准星偏移与前方结果可见性

## 触发与输入

用于近距离交互要求低头对准按钮，导致玩家错过前方机关变化的情况。取得交互相机、有效渲染视口、准星 UI 坐标系、现有拾取入口与距离/遮挡规则、按钮及其结果对象、偏移设置的产品要求。先确认任务是调整交互画面构图，而非扩大目标发现范围或改善武器命中。

需要检查实际项目的屏幕转射线 API 与坐标原点；不能只移动图片并假定拾取自动跟随。设置范围、步长、默认值和是否跨会话保存由项目决定，保留零偏移作为中心布局。只有当前交互相机与其有效视口确定后才计算；窗口最小化或视口宽高为零时停用本次拾取，不用旧坐标继续交互。

## 实施流程

1. 建立近处低按钮与前方可见机关的测试场景。保留原交互距离、相机高度、FOV 和输入灵敏度，记录中心准星下实际操作时的视角与结果可见性。偏移不自动抬镜头，目标是让玩家在更少低头的视角下仍能对准按钮。
2. 定义唯一的交互准星位置数据。以当前玩家的有效相机视口为基准，令纵向偏移 d 表示视口高度比例，向下为正；在左上为原点、y 向下的归一化约定下，位置为 (0.5, 0.5 + d)。若引擎 viewport API 的 y 向上，转换成 (0.5, 0.5 - d)。不要混用全显示器、分屏区域、黑边和 UI 画布尺寸。配置存归一化偏移，不存某次窗口的像素结果；范围须有限且包含零，并让准星中心与必要图形边距留在有效视口内；非法值按设置契约回到最后有效值或零，并同步两条消费路径。
3. 显式转换到所需坐标：有效视口左上角为 (x0, y0)，尺寸为 (W, H) 时，像素位置为 (x0 + 0.5W, y0 + (0.5 + d)H)。显示分支再转换到 UI 本地坐标，处理缩放、锚点与安全区；拾取分支转为相机 API 要求的像素或归一化位置，再调用对应屏幕/视口转射线方法。用图形实际中心而非素材左上角对齐，装饰缩放围绕此中心播放。若输入 API 接受底部为原点的全屏像素，先完成同一显示表面上的 y 翻转，不能仅对 H 翻转而丢失视口偏置。不能把归一化数值直接作为像素，也不能在透视相机中只平移射线起点。
4. 显示中心和拾取查询消费同一个最终位置与同一帧视口/相机数据，在相机更新完成后计算。若安全区约束或布局会夹紧位置，先求最终位置，再供两支使用；避免 UI 后处理移动了准星却仍从旧点发射射线。零值应确实回到相机视口中心，若该点不在 UI 安全布局内，调整准星专用容器而非偷偷夹偏零值。可先用无需时间插值的共同更新；若项目要求过渡，就将当前过渡位置作为唯一锚点，不能只平滑图片。调试显示最终锚点和中心参考射线，核对参考射线上测试点再投影落在锚点。
5. 将最终锚点传入既有选择器：单射线方案从该点生成射线；若已采用区域/多射线选择，仅更新采样中心，不新增射线数量、容差、吸附或目标优先级。保留现有交互过滤、遮挡、资格及距离测量基准，不把 API 的近裁剪面射线起点误作新的玩家可达距离原点。候选高亮、按键提示与提交都使用这条选择路径，不另查相机中心；没有有效候选就清空，提交前依原规则重验当前候选。实际成功与机关结果仍由原交互状态驱动。
6. 将设置变化接入同一位置数据，立即同步显示与拾取；零值恢复中心布局。预览、应用、取消、恢复默认都走同一更新入口；需要保存时写归一化值，取消则恢复预览前值，不让 UI 值与实际取样位置分离。窗口尺寸、UI 缩放、宽高比/黑边、相机投影/FOV、相机/视口切换后重新取得映射；动态渲染比例先区分显示像素与内部缓冲像素，不重复乘缩放。变更后撤销旧候选并从新配置重取样；完成之前不允许用旧焦点提交。暂停菜单或其他非交互模式按既定规则停用拾取，退出时从当前视口重建。
7. 对比零值与候选下移量：玩家站在相同位置，分别自然瞄准同一按钮并触发相同机关，观察是否能同时看清按钮提示与前方变化。选择满足项目构图和操作需求的值，不为改善结果可见性自动改 FOV、相机高度、交互距离、目标大小或瞄准辅助。

## 调参与验收

- 先修显示/拾取对齐，再调偏移幅度。过大偏移使下方目标和提示拥挤时减小幅度，不靠扩大射线命中范围补救。
- 在中心与下移布局、远近目标、相邻小按钮上逐一对准。准星下目标与真实选择一致；遮挡物和超距目标仍不可交互，零值不残留偏移。
- 覆盖项目支持的宽高比、分辨率、UI 缩放、安全区及视口变化。中心参考射线上测试点再投影应落在显示中心，误差阈值按项目像素密度与目标尺寸制定。单射线选择的命中点也须满足该条件；既有区域选择允许结果离开中心时，按其原采样/优先级契约验收，不借对齐验收把它改为单射线。
- 同站位下分别让玩家自然对准按钮，再触发同一机关：记录相机俯仰、按钮/提示位置以及前方结果是否位于画内且未被近物遮住。不是固定相机只挪图标就宣称视野改善。若结果仍在画外，说明偏移不足以解决该布局，不宣称已修复，也不偷偷改变相机或机关位置。
- 快速调设置、取消预览、恢复默认及切换相机后没有旧射线/旧高亮参与提交；同时按交互键也不会误用旧候选。若要求保存，重启后显示与拾取共同恢复设置；最小化/恢复不保留无效视口坐标。
- 显示正确却选错目标时依次查坐标原点、有效视口、UI 缩放/安全区、更新顺序与提交路径。临时回退应同时归零显示和拾取，不能只把图标移回中心。

## 机制边界

本入口拥有交互准星的屏幕构图与拾取对齐，不定义自动瞄准圈、目标吸附、武器弹道或攻击方向。混合战斗游戏应按模式区分交互准星与武器瞄准契约，不能把交互偏移自动传播给射击。

- [交互状态](../gameplay-contextual-ui/SKILL.md)管理焦点、提交及成功/失败，本页只提供一致的取样锚点和目标输入。
- [世界内位置参照](../gameplay-worldspace-indicators/SKILL.md)从世界锚点校对投影与深度；本页锚点先定义于玩家视口，不附着到已选物体。
- [世界目标发现性](../gameplay-world-readability/SKILL.md)解决目标难发现，不负责把取样点移出屏幕中心。
- [方向瞄准姿态](../gameplay-aim-pose/SKILL.md)组合持枪部件与方向帧，不管理本页的交互布局。
- [多射线物体选择](../gameplay-multiray-object-selection/SKILL.md)管理区域取样、遮挡与候选排序；组合时将本页最终锚点作为其采样中心，不能因准星下移而自动启用或扩大选择辅助。

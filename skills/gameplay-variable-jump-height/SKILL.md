# 按住与松开控制跳跃高度

## 触发条件

- 轻点和长按得到同一高度，玩家难以选择低跳与高跳。
- 松开后仍持续升高过多，或再次按住造成免费增高、悬停、额外起跳。
- 若问题只是下降太慢，转到[升降非对称重力](../gameplay-asymmetric-jump-gravity/SKILL.md)，不要把相位重力与保持输入混为同一开关。

## 输入与前置条件

真实起跳成功事件、跳跃按下/保持/松开状态、输入与物理更新顺序、向上轴和垂直速度、既有初始起跳速度/重力、接地与撞顶事件、计时时钟及暂停/死亡/传送/控制中断规则。确认是否支持空中跳、缓冲起跳、移动平台和外部击飞；分别声明哪些真实起跳可接受高度控制。先保存固定高度跳跃的基线，不修改原有可跳条件。

## 实施步骤

1. 记录同一初始位置与速度下的轻点、短保持、长保持轨迹，包括实际起跳时刻、松开时刻、顶点高度和上升时间。规定目标低跳/高跳范围及容差，使用项目世界单位和时间单位。
2. 只在原控制器成功执行一次合法起跳后，创建属于该次跳跃的高度控制状态；起跳冲量仍只施加一次。单纯走下平台、空中重新按住或一直保持输入不能创建此状态，也不能补充跳跃次数。
3. 选择一种项目实现分支，先独立完成和调参，不默认叠加两种效果：
   - 松开截速：长按使用原完整跳跃轨迹。在仍上升且首次松开时，将向上速度降到不高于当前值的项目截速上限，或一次性乘以项目选定的衰减比例，然后消费截速机会。只修改向上分量，不逐帧重复相乘，也不把已经向下的速度反转。
   - 有限保持助力：保留一次起跳速度，仅在该次跳跃仍上升、按键仍保持且有限助力时长未用尽时，添加沿向上轴的加速度。按物理步长积分，限制助力时长与总效果；先使助力小于向下重力，避免净向上加速。释放、预算耗尽或离开上升阶段立即关闭，重新按住不续期、不恢复旧预算。
4. 写清同一物理步的输入采样、真实起跳、高度控制、重力积分和碰撞处理顺序，并由单一运动更新负责垂直速度。按下和松开都发生在首个物理步前时，仍按已声明的轻点语义处理，不能因未采到保持状态而丢掉一次合法起跳。
5. 缓冲命令在松开后才成功起跳时，先服从[输入缓冲](../gameplay-jump-input-buffer/SKILL.md)的保留/取消规则。若该命令仍允许执行，高度控制按已松开状态开始：截速分支执行低跳策略，助力分支不给保持助力；不偷偷要求额外按下，也不把旧保持时长变成新许可。
6. 顶点、真实撞顶、落地及中断结束本次高度控制。撞顶后以碰撞求解结果为准，不能在后续步继续助力把角色推入顶面；若[顶角纠偏](../gameplay-ceiling-corner-correction/SKILL.md)成功避开接触，按其最终碰撞结果决定是否结束。新合法空中跳若被项目允许，建立新状态而非续用旧状态。
7. 与相位重力组合时先选当前升降重力，再应用高度控制的既定截速或助力，最后只积分一次。分别开关两项，确认低/高跳差异来自输入时长，而不是新增跳跃、重复重力或视觉缩放。

## 调参顺序

先固定水平速度、起跳速度和上升重力，确定长按上限；截速分支再调首次松开的速度上限/比例，助力分支再调助力加速度与持续预算。扫过多个松开时刻，要求在容差内保持越久顶点不降低，超出有效窗口后高度不继续增长。最后复测关卡可达性和低顶路径，不用无限助力补偿不合适的初始速度。

## 失败处理

- 轻点与长按无差别：先查松开是否被输入采样丢失、状态是否创建、截速是否发生在上升期，再调幅度。
- 重新按住增高或无限漂浮：查助力预算、关闭锁存和真实起跳事件；禁止保持状态刷新预算。
- 缓冲轻点意外成为高跳：查成功起跳时保持状态及早松语义，不修改缓冲窗口来掩盖问题。
- 撞顶后粘住或穿透：关闭高度控制并恢复碰撞优先；不要缩碰撞体或补施起跳冲量。

## 验收

- [ ] 相同初始条件下轻点顶点低于长按，多个中间松开时刻的高度趋势及上限符合目标；记录顶点与上升时间，不凭动画判定。
- [ ] 无限保持、松开后重按、下降中按住和走下平台都不产生额外跳跃或延长旧预算；已有空中跳次数不变。
- [ ] 首步轻点、缓冲后早松、离地宽限起跳与同一步落地/起跳的输入语义一致，一次合法起跳仅初始化一次高度控制。
- [ ] 正中撞顶、擦角纠偏失败/成功、低顶窄缝与支持的移动平台不会穿透、粘顶或免费增高。
- [ ] 不同渲染帧率及项目支持的物理步长下高度差异在声明容差内；暂停、死亡、传送和控制中断不残留助力或截速机会。

## 组合与边界

- [离地宽限](../gameplay-jump-forgiveness/SKILL.md)决定晚按是否仍可跳；[跳跃输入缓冲](../gameplay-jump-input-buffer/SKILL.md)保留早按命令。本项只处理它们已批准的实际起跳。
- [升降非对称重力](../gameplay-asymmetric-jump-gravity/SKILL.md)按运动相位选择重力，与按键持续时间独立。
- [事件形变](../gameplay-motion-deformation/SKILL.md)只改变视觉层，不能以拉伸冒充真实高度变化。

# 移动驱动的植被接触音

## 效果预览

相同慢行与快行路径，两株灌木只在接触时可视化发声；右按速度改变振幅，退出静音，未伪造强度或方向通道。声音变化以图形示意。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![走得轻、撞得快，沙沙声应不同：使用前后对比](assets/before-after.gif)

## 何时使用与所需输入

用于玩家慢慢穿过灌木与快速撞入灌木却听到相同触发音的问题。取得既有移动状态、植被接触/重叠查询、对象及生命周期标识、可控制的声音素材/实例，以及项目的空间发声和并发规则。不为声音改动角色速度、碰撞结果或植被物理。

先定义三类输入的语义：速度采用哪个坐标系、单位及采样时点；“移动强度”由哪个既有系统提供、表示什么及其有效范围；方向是实际运动方向、输入方向还是接触方向。不要将输入杆幅度自动当成接触力度，也不要用速度再次算出一个未经定义的“强度”。缺少强度定义时保留适配接口并注明未接入；只完成速度响应原型，不宣称三输入版本已完成。

## 实施流程

1. **限定有效接触。** 只接收指定交互主体与允许发声的植被对象之间的接触。明确采用重叠体、扫掠还是已有碰撞事件，排除相机、武器及纯视觉邻近关系。给同一对象的多个碰撞体建立合并规则；没有有效接触时不能仅因玩家高速移动而发声。高速穿越若会漏检，修复接触采样或使用项目已有扫掠结果，不凭画面距离补触发。
2. **建立对象级状态。** 按植被对象和生命周期维护有效接触集合、声音句柄、上次输入与“未接触 → 接触中 → 收尾”的状态。进入时创建或取得受控实例；持续接触更新该实例，不在每个移动帧重播同一条音。多主体接触同一植被时明确采用主导接触、合并输入或独立受限实例，避免最后一个回调随意覆盖全部输入。
3. **校验并映射。** 记录慢走、普通移动与快速进入时的真实输入范围，检查有限值、单位及方向坐标系。按项目可调范围归一化并限幅，零速度时不归一化零向量；非法输入采用静默/中性回退，不把异常峰值发送给音频。先只改变速度，建立慢速较柔、快速接触较强的可试听响应，再接入已定义的强度通道。曲线和音频目标由素材决定，不预设通用 dB、音高或冲量公式。
4. **单独处理方向。** 向声音适配器传递已说明坐标系的方向，与速度、强度分开记录。项目若已有方向响应方案，明确它控制何种参数，再做正反向对比；未定义方案时保持中性并标记待设计，不自行把左右运动映射为立体声声道。空间发声位置沿用项目规则，不混同方向输入与监听者相对位置。
5. **限制更新与发声数量。** 选择素材适用的受控持续声、可延展声或受限短片段序列；持续素材不可用时，不强行循环有明显撞击头的短片段。输入更新、片段启动与真实新接触分别处理，配置项目需要的平滑、重触发门限与声部上限。边缘抖动先检查接触稳定性和重复订阅，不能只靠无限延长冷却掩盖问题。
6. **处理停留、离开与中断。** 静止留在植被中时将运动贡献降至中性/静默，不持续制造穿越声。最后一个有效接触退出后按素材收尾并释放句柄；重新进入按当前接触状态恢复，拒绝旧生命周期回调。暂停、卸载、对象销毁及对象池复用均需清理订阅和活动声部。并发超限时按项目优先级降级，不让一个灌木的退出停止另一个灌木的声音。

## 调试与验收

先检查接触与输入日志，再固定素材分别调速度、强度、方向，最后调平滑、退出尾音和并发。保留各输入与声音参数的对应记录，避免三项同时变化而无法解释效果。

- [ ] 植被外快速移动无接触音；同一植被多碰撞体不重复启动；慢走、快跑和快速穿越均有正确接触记录。
- [ ] 保持其余输入不变，速度变化产生有界、可解释的输出；强度和方向各有独立语义与接入状态，缺失输入不被伪造。
- [ ] 停留、边缘反复进出、零方向、异常值、同时接触多株时无无限重启或实例串扰；退出/卸载/复用后无残留声部。
- [ ] 在目标项目实际开启音频，比较相同路径慢速穿过与快速撞入：前者较柔，后者较强，且无不合素材的跳变、爆音或机械重复。核听方向方案时只验证项目实际选择的映射。
- [ ] 日志通过但未核听时，交付标为“参数与生命周期检查通过，听感待验收”；不能以静音画面或参数变化代替可听结果。

## 机制边界

[物理阶段音频](../gameplay-physics-stage-audio/SKILL.md)处理断裂、倒伏、撞地阶段与变体；本页处理持续植被接触中的移动参数响应，不把高速穿越等同于断裂事件。[次级运动](../gameplay-secondary-motion/SKILL.md)处理视觉装饰跟随，不负责本页的声部或输入映射。

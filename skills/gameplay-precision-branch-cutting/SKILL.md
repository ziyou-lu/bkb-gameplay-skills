# 枝条基部精确命中与分离

## 触发与前置条件

仅在任务明确要求“打中枝根一击脱离，打偏只摇晃并受到较少伤害”等位置影响结果的修枝玩法时采用。若只是增强采集手感、倒伏或碎片表现，使用[破坏与采集过程](../gameplay-breakables-loot/SKILL.md)，不自动改变伤害和采集规则。

取得工具有效攻击窗口与命中事件、枝条唯一身份、所属父级/连接、实际接触点及其坐标空间、枝根区域定义、已有伤害/分离接口。明确非基部伤害的接收者、基准值、减量规则及累计耗尽是否允许脱离；未定义时先确认这些玩法选择，不推断为手部或玩家受伤。还需知道分离后物理、产物和库存的既有职责。

## 实施流程

1. **锁定目标和连接。** 建立 `branchId`、`parentId`、当前连接身份及连接/分离状态，将碰撞子形状映射回同一枝条。枝根取该枝条真实连接位置，不取整棵树中心、模型原点或屏幕准星。先在一条仍连接的枝条上显示工具接触、枝根区域和父级关系。
2. **定义局部判定区域。** 选择项目支持的枝根局部体积/标记区域；也可由明确的连接位置、局部枝轴和尺寸构造距离判定。写明单位、缩放和边界相切语义。把实际工具接触点转换到对应枝条/连接局部空间再分类，随树干旋转与移动更新；不能只按瞄准点或大范围 trigger 进入认定根部命中。
3. **提交单次有效打击。** 仅接受既有攻击窗口内、工具类型有效且目标仍连接的命中。按一次挥击身份选择一个有效目标及接触结果，再锁定本次处理；多碰撞子形状、连续物理回调或相邻枝根重叠不能让一次普通挥击误切多枝。优先次序使用项目既定的扫掠先后/接触规则，不按回调顺序随意挑选。若项目明确支持多目标，另行定义其目标预算，不悄悄扩大本流程。
4. **基部命中走一击分离。** 对锁定枝条和连接做一次状态检查及提交，由连接态进入分离态，调用既有部件分离接口。使旧连接、跟随与相关碰撞归属同步失效，保留该枝条身份和世界姿态，按项目已有方式交接自由运动。不要销毁整棵树、批量断开兄弟枝条或重复生成同一枝条副本。
5. **非基部命中走减量伤害与摇晃。** 进入明确的枝条伤害接口而非角色伤害接口；例如项目采用乘数时，先定义基准伤害再应用小于基准的有效倍率。非致命结果保持连接，以连接点为枢轴播放有限的摇晃并回到当前连接姿态。摇晃不移动权威判定根部或累计修改静止姿态。若允许累计伤害耗尽，将该终态交给同一个一次性分离入口；不能为实现“摇晃”覆盖已经确认的终态。
6. **保留现有系统边界。** 分离事件只描述哪条枝、哪个连接、哪次打击及结果。产物生成、拾取/库存、碰撞和刚体响应沿用项目已有接口；脱离不等于入包，不为示范额外加入砸伤、玩家手部扣血或新物理架构。卸载、重载和重放时恢复连接终态与已处理事件，取消失效摇晃，避免旧回调再次结算。

## 调参顺序

先调枝根区域覆盖与可读边界，覆盖细枝、粗枝和不同朝向；再调非基部伤害、累计终态规则；最后调摇晃幅度/衰减及已有攻击节奏。区域过大使精度无意义，过小使有效根部难以命中，应结合工具形状和项目尺度测试。伤害倍率、冷却与动画时长均为项目参数；冷却不能代替一次挥击的事件去重。

## 验收与故障定位

- 同一条完整枝条分别测试根部、非根部和边界：根部一击只分离目标枝条；非根部按定义减量并摇晃，非致命时保持连接，累计耗尽按项目规则处理。
- 旋转/移动树干、改变枝条局部缩放或模型原点后，真实连接处仍判为基部；错位先检查接触坐标和连接变换，不先放大容差。
- 多子形状、同帧重复回调、连续接触、相邻枝条交叉与同一挥击多接触下，只产生允许的一次结果；已脱离枝条不再走附着枝条逻辑。
- 高速挥击检查扫掠与接触采样是否漏过细枝；无有效接触不得仅凭视觉贴近分离。区分漏检、分类错误与显示延迟后再修复。
- 摇晃中再次命中、暂停恢复、父级销毁和重载后，无旧连接拉回、永久姿态偏移、双产物或重复伤害；库存和玩家/手部生命值不发生未要求的变化。
- 记录命中分类、权威分离事件与可见脱离时刻；逐项报告实际项目测试结果，不把可见掉落当作库存或物理正确的证明。

## 组合与边界

- [突出部接触](../gameplay-prop-appendage-contacts/SKILL.md)处理枝条随主体撞地的覆盖与响应；本页处理工具命中位置如何改变采集结果，地形接触本身不授权精确砍枝。
- [几何事件对齐](../gameplay-geometric-event-alignment/SKILL.md)处理物体经过操作边界时事件过早/过晚；这里先分类同一枝条上的有效命中位置，不把经过平面直接等同枝根命中。
- [受伤区域容差](../gameplay-hurtbox-tolerance/SKILL.md)改变角色是否受伤；这里是在已成立的工具命中中选择枝条结果，不调整角色 hurtbox。
- [破坏与采集过程](../gameplay-breakables-loot/SKILL.md)接收已确认终态组织产物过程，不拥有本页的枝根分类与一击分离规则。

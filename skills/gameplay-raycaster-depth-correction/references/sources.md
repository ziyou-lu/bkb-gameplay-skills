# 来源与工程边界

## 作者解释与可见对照

- 来源：[howitspawns 的历史解释影片](https://www.instagram.com/p/DejfFjFlA18/)，规范来源 ID：DejfFjFlA18。2026-10-23 只读检查作者正文与部分画面；不是官方游戏捕获，也没有独立执行其程序。
- 作者描述简化方格迷宫、等高墙和逐列射线：每列命中后按距离的倒数决定墙柱高度，距离加倍则高度减半。全斜射线长度会让正对镜头的平墙两侧投影变矮，形成 fishbowl/fisheye 弯曲；改用距离在观察方向上的分量，平墙的深度一致，投影边缘恢复直线。作者另说明对近墙距离设最低值，以避免除法溢出，没有提供阈值。
- 可见顺序：俯视格子与单射线 → 扇形射线和走廊墙柱 → 相对水平虚线弯曲的前墙 → 平行前向深度标记 → 墙边恢复直线。弯曲样本标注“own run”，只作为作者标签，不作为本库已验证真实运行或复现的证据。
- 正文把机制归于 id Software 公开 wolf3d 的 WL_DRAW.C / CalcHeight，但此次没有独立打开或核读该仓库。画面显示片段 `nx = gxt-gyt;`，变量语义与上下文不足，不作为可运行算法或历史实现验证。
- [作者关于制作的回复](https://www.instagram.com/p/DejfFjFlA18/c/17899412949612511/)说明使用 AI，但多数工作在动画侧，并提到动画工作室式制作。应把影片视为作者制作的解释性演示，不由动画外观推断原游戏源码、真实引擎执行或性能。

## 参数与未知项

正文提及 64×64 最大地图作为历史细节，不是本技能地图限制或默认设置。片中 FOV 是作者自选，没有确认数值。距离保护阈值、世界单位、投影焦距、射线归一化约定、格子遍历实现、纹理裁切与实际渲染数值类型都未提供完整配方。没有音频核听、目标引擎运行、性能测量或独立历史源码核验。

## 工程选择，不是作者已证代码

执行入口的命中点减相机位置后点乘单位前向、欧氏长度与未归一化射线参数的区分、DDA 返回值契约检查、无效/后方命中先拒绝再正值保护，以及 FOV 到像素焦距的公式，是本库为现有渲染器迁移提供的工程推导。它们不来自影片残缺代码，也不应标为 Wolfenstein 官方实现。

平面投影列采样、相机眼高保留、有限值与整数转换检查、屏幕裁切保留纹理坐标关系，以及正面/斜面/边缘/近墙验收均是拟议实施与测试步骤，未在源程序或目标工程执行。该技能仅修已有平面等高墙 raycaster 的深度分母，不提供完整渲染器、任意三维投影、碰撞或镜头反馈实现。

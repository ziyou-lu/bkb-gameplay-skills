# 方向瞄准与分件姿态

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 整张 sprite 的旋转无法表达不同方向的持枪外形。
- 上/下瞄准或左右翻面时肩部、手臂接缝、持握关系和绘制层级跳变。

## 先确认的输入

真实瞄准/开火方向、可用分件与方向 sprite、持握锚点、各部件绘制层级、当前翻面规则，以及是否采用 stack 表示。

## 分步机制

1. 先检查静止组合和持握关系，明确哪些部件应跟随瞄准、哪些保留自己的方向表示。不要从最终画面推断自动瞄准或真实 3D 实现。
2. 若需要分件姿态，可参考 CW0Su7-sy5- 的头、躯干衣服、手臂、腿与枪组合，再按需叠加部件上下呼吸和瞄准时头/身前后位移。
3. 检查肩部外形是否仍需按方向切换上衣 sprite；位移幅度、换图边界和层级由项目决定，不从视频猜数值。
4. 俯视瞄准可另选混合表示：CW8BHbmsy_r 展示腿/头/眼睛采用普通方向 sprite、躯干采用 stack。逐件对照方向外形，再检查组合锚点和前后遮挡；它是不同方案，不与前例拼成必须全做的教程。
5. 绕角色一周与快速切向检查显示瞄准和真实开火方向一致；中断或翻面后恢复正确的方向帧、锚点与层级。

## 适用限制

- 两帖均为 raycastly 转载并署名 Faxdocc（Twitter），只核读转载，原发布未核验，不能把转发账号写成原创作者。
- CW0Su7-sy5- 只有四项已核演示，不补独立“旋转枪”步骤；角度阈值、位移幅度、代码和绘制实现未知，不推断骨骼工具。
- CW8BHbmsy_r 武器独立标签缺失，堆叠层数/层间偏移/角度阈值未核验；8 格素材不证明通用必须八方向。最后枪口环与碎片不是独立制作步骤或玩法规则证据。
- 音频与代码未核验；表现组织不是修改碰撞、伤害或加入自动瞄准的理由。

## 验收

- [ ] 绕角色一周检查头、眼睛、腿、躯干与武器朝向关系，帧切换前后锚点和遮挡不跳变。
- [ ] 上/下瞄准、左右翻面和换图边界附近，肩部/手臂接缝、持握点及绘制层级符合设计。
- [ ] 呼吸与姿态位移不改变实际射击/碰撞；快速切向与中断后不残留错误方向 sprite，显示瞄准与真实开火一致。

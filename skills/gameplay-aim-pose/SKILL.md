# 方向瞄准与分件姿态

## 触发条件

持枪角色转向像整张纸片旋转，或上/下瞄准、翻面时肩部、手臂和遮挡关系跳变。

## 输入与前置条件

真实瞄准/开火向量；头、衣服、手臂、腿和武器素材；持握锚点；方向帧、翻面及绘制层级。先确定表示方案，不改变射击规则。

## 实施步骤

1. 建立中性组合：把各部件放在共同角色坐标下，标出肩、握把与枪口锚点。用实际开火方向驱动姿态选择，避免显示朝向与命中方向各算一套。
2. 分件姿态方案：用头、躯干、手臂、腿、枪的分件组合保持持握；按瞄准方向切换衣服/肩部外形。先修静止接缝，再叠加头身前后位移与上下呼吸。
3. 俯视混合方案：可让腿、头、眼睛用普通方向 sprite，躯干用 stack 表示。先验证每个方向的躯干轮廓和锚点，再决定层间偏移与遮挡；不要求同时采用分件方案的全部动态。
4. 为方向区间统一换图、翻面和层级规则。在相邻方向交界缓慢扫动，若帧来回切换，调整分区或采用项目允许的稳定化，不能靠扩大枪口特效遮掩。
5. 快速换向、打断与重启时从当前瞄准重建姿态，移除过期呼吸/位移叠加；不从外形旋转增加自动瞄准、碰撞或伤害。

## 参数调整

分别调整方向区间、持握偏移、呼吸幅度和层级；先用关闭呼吸的基线排查接缝。stack 层数只增加到目标视距轮廓足够连续，方向数按素材覆盖选择，不固定八方向。

## 验收与失败处理

- [ ] 绕角色一周并覆盖上下瞄准、左右翻面与边界反复切换，肩部和握把不脱节。
- [ ] 比较显示枪口方向与实际发射方向；纯姿态改动不改变命中/碰撞。
- [ ] 中断和再次启用没有旧方向帧、错层或位移残留；出现错层先查排序规则而非添加更多素材。

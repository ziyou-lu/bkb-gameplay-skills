# 带时间戳的地面效果

## 效果预览

左侧新铺地面效果会给旧片段续时；右侧各位置按自己的生成时间到期，较早片段消失时较晚片段仍保留。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![每一块冰，各算各的时间：使用前后对比](assets/before-after.webp)

## 触发与输入

移动拖尾或区域印记不断添加，但不同位置必须分别到期时使用；不要用整张 decal 的统一计时器抹掉新旧片段。取得地面范围/楼层、印记位置与形状、世界到纹理映射、目标分辨率、效果寿命、统一时钟，以及已有玩法网格和其进入/停留/离开规则。先决定重叠是否刷新、是否需要保存多个独立效果；单份时间戳不能表达任意多层叠加。

## 实施流程

1. **分开显示与权威状态。** 纹理保存显示所需的局部生成时间，地板 decal 负责读取并显示；独立地面网格决定某位置是否拥有已有的玩法状态。不能从贴图颜色推导冻结、伤害或减益，也不让 shader 成为玩法判定来源。
2. **建立有界映射。** 为一个明确地面区域定义世界坐标到 UV 的变换，用四角和中心的调试印记校准方向、缩放及高度/楼层筛选。拒绝范围外写入和采样，禁用环绕导致的另一侧印记。大范围需要分块时，为每块保存独立原点、边界与纹理；跨块印记只写相交块，重用块之前清除旧状态。
3. **存时间数据，而非颜色。** 选择能无损满足目标时间范围/精度的浮点渲染目标，或明确设计可解码的时间编码；未经编码的秒数不得写入会把大于 1 的数截断的归一化通道。关闭对时间数据的颜色空间变换。独立保存覆盖/有效性标志，清空时使其无效；不能用时间戳等于零判断空白，因为开局零时刻的印记也有效。
4. **统一时钟与重盖语义。** 写入、材质当前时间和网格到期计算使用同一纪元、单位和暂停策略。为长局选择足够精度，或同步迁移存活时间戳与当前时间到新纪元；禁止只重置当前时间。对单层效果，项目可选“最近印记刷新”或“保留原到期时间”，并在纹理和网格实行同一规则；不要用普通透明混合平均两个时间戳。不同寿命或不同效果共存时需要额外数据/层，先确认需求，不默认扩展系统。
5. **写入局部印记。** 对目标形状覆盖应用已选重盖策略：刷新模式写当前时间并置有效；保留原到期模式保留仍存活的已有时间戳，仅为空白或已过期位置写当前时间并置有效。纹理与网格必须使用相同判定。需要读取旧值的写入使用引擎支持的读改写或独立前后缓冲，不假定同一纹理同时采样/写入必然安全。拖尾可用一串小形状覆盖移动路径，区域效果可用圆形等印记；间距由移动速度、形状尺寸和连贯性要求决定，不绑定某个固定采样周期。快速移动可沿本次路径补样，传送则依项目规则断开，避免凭空连接整段地图。覆盖边缘可有独立软化，但时间戳应原样选取/解码，不能经双线性插值、普通 mip 平均或透明混合生成并不存在的年龄。
6. **按每个位置的年龄显示。** 对有效数据计算 age = now - createdAt，并以 0 ≤ age < lifetime 判断存活。寿命须为项目定义的正值；负年龄视作时钟/纪元错误而不是永久有效。可在存活区间内独立设计淡出，但淡出权重不反写生成时间。先用硬边年龄调试显示确认新旧片段，再加外观；材质采样有效性与时间必须来自匹配数据，不能让空白邻居参与平均。
7. **同步网格与清理。** 用同一印记事件、空间范围、时钟、寿命和重盖策略更新权威网格。先明确格子与形状相交/中心采样等覆盖规则，给显示与判定约定允许误差。网格到期必须实际撤销已有状态，而非仅隐藏 decal；遵守项目已有进入/停留/离开逻辑，不额外施加冻结或伤害。纹理中过期值可以被材质拒绝而暂留，但区域卸载、重新开始和资源重用时须重置有效性、网格及纪元。

## 调参顺序

先验证映射、时间范围和重盖规则，再调寿命、纹理精度、网格精度与拖尾间距，最后调边缘和淡出。以最窄印记、最高移动速度和目标视距观察空洞及判定误差；提高纹理分辨率不自动提高玩法网格精度。若每个位置只保存一个时间戳，就保持单层语义，不用混色冒充多个独立到期的状态。

## 验收与失败恢复

- 同时保留较早和较晚的印记，较早片段先消失，较晚片段仍存活；独立检查零时刻印记有效、空白始终无效。所有片段一起消失时先查是否仍在用整张 decal 的计时器。
- 测试时间超过归一化颜色范围以及目标最长会话；若时间截断或抖动，检查格式、编码与精度，不把寿命改短掩盖问题。暂停/恢复、重新开始后，显示和网格使用同一时间策略。
- 两个不同时间的印记重叠、原地连续盖章后，结果符合选定刷新规则；边缘和缩小视图不会因过滤产生虚假年轻/老化区域。异常先查时间通道混合、过滤和 mip 处理。
- 快移、转弯、区域印记、传送、纹理边界和分块交界均符合覆盖约定；不环绕到另一侧，不泄漏到另一楼层。映射失败时拒绝该写入并报告区域，不靠 UV 钳制把所有范围外位置堆到边上。
- 在印记创建、重盖与到期边界比较显示和网格状态；过期区域不继续触发已有玩法规则。若不一致，检查事件、纪元、覆盖和到期条件，而不是从可见像素反读权威状态。
- 卸载、重用区域和重开后无幽灵印记或遗留网格状态。记录实际检查结果；未运行目标项目时不宣称已通过。

## 职责边界

[表面余效](../gameplay-surface-aftermath/SKILL.md)负责事件后按承载地形采样、截断边界并生成贴地网格，本技能负责纹理中的局部时间与独立网格到期，不自动解决台阶贴合。[状态驱动表面动画](../gameplay-state-driven-surface-motion/SKILL.md)把机器状态映射到 UV 运动，不保存各地面片段的创建历史。需要危险区域表现对齐时再组合[攻击可读性](../gameplay-attack-readability/SKILL.md)，保留现有玩法规则。

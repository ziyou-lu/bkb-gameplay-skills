# 镜头冲击与短促聚焦

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 事件有特效但重量感弱。
- 现有镜头抖动过强、漂移或影响瞄准。
- 钩爪、冲刺或跑酷已有高速运动，但速度线、视野变化与模糊缺少协调，或妨碍判断路径。

## 先确认的输入

基础镜头驱动、事件强度/方向、玩家控制方式、屏幕比例和减少镜头运动选项。高速分支另确认实际速度/轨迹、基础 FOV、已有后处理，以及各效果的恢复和关闭方式。

## 分步机制

1. 把反馈偏移与基础跟随/瞄准解耦，以可归零的临时偏移叠加，不直接累计到相机世界坐标。
2. 匹配事件方向：着地偏向下，后坐沿武器反向，击打沿攻击方向；推近可用于稀有重击而非替代所有震动。
3. 在同一段动作中做无/小/大三档单变量对照，选择能够读出事件的最小强度，避免把最强档自动定为成品。
4. 给幅度、频率、衰减和重复触发上限独立控制；多目标同帧事件按最高强度或预算合成，策略按项目决定。
5. 区分画面震动与改变实际瞄准/碰撞的玩法后坐；除非用户明确需要，不借视觉优化改命中判定。
6. 测试推近后的视野边缘、快速转向、场景切换与中断，支持关闭/减弱并恢复基础镜头。
7. 高速移动可按需组合屏幕边缘速度线、速度相关 FOV、径向模糊和震动。DRfuWODEvzF 是四项组合对照，不提供单项收益或通用数值。迁移时保持真实速度与路线一致，先分别开关再评估组合；按项目定义映射与上限，FOV、模糊和震动分通道控制，在减速/中断时回到各自基准。优先保证准星、钩爪目标、转弯和落点可读；如果影响舒适度或操作，就减弱或关闭，而不是再加模糊遮盖问题。

## 适用限制

- DRfuWODEvzF 的两段 HUD 速度不同，不是同速实验；边缘放射模糊与镜头变化不能证明角色实际加速，也不能证明某一层单独有效。FOV 范围、速度映射与各强度参数未公开，不给通用推荐值；DSPbCDyjfDD 只是同素材转发，不另增证据样本。
- DVGe1E9iDdi 是后坐强度对照，DYfFEpzIa-H 是爆炸加震动对照，均没有通用最佳数值。
- DcXJwumOuBK 的弹球案例在 Camera Shake 标签下可见棋盘背景位移；没有验证震动算法、方向、幅度或衰减，不将背景位移解释成实际球速或反弹规则改变。
- 可复用 shake 脚本是作者声称，不代表已取得或验证脚本；该爆炸帖声音仍属未来计划。

## 验收

- [ ] 事件结束镜头回到原基准，不累积漂移。
- [ ] 连续命中不会让镜头无限放大，减少运动设置有效。
- [ ] 高速方案在同速度/同轨迹控制下逐项和组合对照，分别记录路径识别与舒适度，不将不同 HUD 速度的原帖当成受控测试。FOV、模糊、速度线及震动均可减弱/关闭；减速、停止和中断后不残留错误视野或模糊。
- [ ] 准星、危险边界、落点和下一步路径仍可读；弹球场景尤其检查连续碰撞后的球位、下一接触面和运动方向。记录对照结论而非仅评价更炫。

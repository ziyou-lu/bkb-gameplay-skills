# 装饰跟随与次级运动

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 角色运动正确，但装饰没有跟随感或受控滞后。
- 转身、翻面、传送或帧率变化后出现链条跳变、反向翻折或持续振荡。

## 先确认的输入

父节点运动/朝向、装饰锚点、基础形状、链段关系与约束，以及已有弹簧/阻尼或动画驱动。先确认其是视觉装饰，不承担真实角色朝向、碰撞或控制。

## 分步机制

1. 保留无次级运动基线，按行走、转身、跳跃和冲刺比较装饰是否帮助读出动作。
2. 以父节点驱动装饰锚点，用受控滞后表现跟随，不延迟真实角色朝向。眼部或其他装饰先按现有结构验证，不自动套用链状解法。
3. 对头发/链状装饰，可参考 DbS8p3VuhkL 的头后锚点、距离约束和弹簧/阻尼，节点数与表现形状按项目需要。先约束关系再调跟随强度，避免把来源五点链当作通用骨骼架构。
4. 在传送、转向翻面和帧率变化时重置或稳定积分；回到保存的基础形状并清理无效速度，处理取消、死亡或切场。

## 适用限制

- DbS8p3VuhkL 展示五点链、递减圆形与描边，部分编号不全，代码未执行；不能当作独立波浪动画或物理正确性证明。
- DerYowOhdHs 只支持眼部次级运动这一用途，不证明眼部也使用头发链、距离约束或相同弹簧算法。其跑姿、朝向修正和敌人等待首击只保留为来源观察，不由方向动画或次级跟随提供行为实现。
- NeonBlade 来源引擎标签不一致，不推断引擎选型；音频和完整实现未验证。

## 验收

- [ ] 行走、转身、跳跃和冲刺中锚点稳定，装饰滞后不改变真实朝向、碰撞或操作结果。
- [ ] 快速翻面、传送、死亡与重进后无反向翻折、残留速度或永久振荡。
- [ ] 帧率变化时约束和跟随仍稳定，节点数量/形状按项目需求而非照搬五点示例。

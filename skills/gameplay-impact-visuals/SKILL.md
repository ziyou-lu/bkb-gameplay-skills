# 接触闪光、冲击帧与粒子

## 效果预览

命中缺少清楚的接触标记；少量火花，明确接触位置；表现辅助｜用局部闪光与短粒子确认真实接触。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![击中哪里，火花就从哪里出现：使用前后对比](assets/before-after.gif)

## 触发条件

- 命中或非战斗碰撞成立，但画面没有清楚的接触标记。
- 普通命中与暴击使用同样表现，或粒子遮挡判定。
- 待机/常驻氛围粒子持续吞没角色轮廓，妨碍辨认站姿和运动。
- 已有弹壳、碎片或血迹需要在短时清理与较长战斗记录之间选择寿命，并验证累积预算。只处理这一问题时从第 4–6 步开始，不要求加命中闪光或改变发射/命中规则。

## 输入与前置条件

事件位置、接触法线/攻击方向、目标可见性、轻重级别、背景对比度与减少闪烁设置；对常驻特效先确认其仅为装饰，还是承载真实状态/危险提示。对残留另确认生成事件、短时/本局等寿命目标、当前表示与数量、重开/卸载清理规则，区分发射弹壳、命中血迹和真正可交互产物。

## 实施步骤

1. 从真实事件位置和方向建立接触锚点，先做局部闪光/轮廓，再决定是否需要重击剪影、冲击帧或爆发线；发射残留不触发命中反馈。
2. 将火花、碎屑、尘团绑定接触点与材质，沿受力/穿透方向分布。burst 负责瞬间接触，trail 负责运动轨迹，慢余尘负责衰减，三者不能都成为持久危险标记。
3. 漫画碰撞文字可作短促确认并淡出，但不得冒充伤害/得分。对重复接触按真实事件身份去重，避免同一碰撞刷出多次确认。
4. 对已有弹壳、血迹或碎片单独选择短时、场景或本局寿命；不默认停火即清除，也不跨局无限保留。可交互产物与纯视觉实例使用不同管理路径。
5. 在代表性晚局密度下量测数量、遮挡和更新成本，再决定数量上限、远处降级或批量表示。项目若采用 HISM 一类批量实例组件，可把相同网格/材质且无需独立动态行为的残留归为一组，保存每项变换及清理标识；仍需独立运动或交互的对象保留原管理路径。改变表示时核对材质、变换、碰撞与动态行为，不以实例化名词保证容量。
6. 为每类短时效果设置结束/中断恢复；本局残留在重开/卸载清理。检查常驻装饰对轮廓的遮挡，优先删减或移位；承载状态信息的效果须先提供替代提示。
7. 低特效/减少闪烁模式仍用局部形状或轮廓说明命中，不能以关闭强闪为代价隐藏关键结果。

## 调参顺序

分开调闪光持续、爆发数量、方向散布、尾迹寿命和残留预算。先单目标再高速连击/多目标对照；以角色、危险区和下一招能否辨认为上限，而不是最大视觉密度。

## 失败处理

材质闪白不复位时修恢复所有权；连击遮挡先减密度/寿命；晚局超预算按既定降级策略处理装饰，不删除交互产物。常驻效果携带危险信息时不能直接移除。

## 验收

- [ ] 能指出接触位置与受力方向，粒子不从无关中心冒出；冲穿攻击的同地图/同动作对照中，视觉新增点应对应真实命中，而非凭残影误判接触。
- [ ] 待机和运动时分别开关常驻特效，比较轮廓、下半身和脚边可读性；删减装饰不丢失真实状态/危险提示，也不擅自改伤害规则。
- [ ] 连击场景仍能读出目标、危险区、生命值和下一招；连续弹球碰撞中，粒子与文字不遮挡球的去向，不把同一次接触回调重复显示为多次事件。
- [ ] 减少闪烁后仍有清楚反馈；结束/中断后材质和屏幕恢复。
- [ ] 残留在代表性的晚局密度下不遮关键目标/危险；记录所选寿命和表示的实际成本，不能以少量弹壳画面通过大规模验收。
- [ ] 短时清理、本局保留及重开/卸载分别符合约定；表示改变后独立核对碰撞、动态行为、材质与变换，没有把可交互对象默默降成纯视觉实例。

## 组合与边界

只在需要相应机制时读取，沿用其事件与预算约束：

- [命中停顿与表现节奏](../gameplay-hitstop/SKILL.md)
- [攻击预警与反制可读性](../gameplay-attack-readability/SKILL.md)

- 水洼等余效悬空或穿出承载边界：[贴地表面余效](../gameplay-surface-aftermath/SKILL.md)。本技能管理通用余效与既有战斗残留的生命期、遮挡预算，不复制表面生成管线。

- 炮侧烟尘使用[射击/喷射反馈](../gameplay-shooting-feedback/SKILL.md)，发射余烟不当作接触命中。
- Boss 屏障材质需求先看[Boss 序列与能力边界](../gameplay-boss-sequences/SKILL.md)，不提供完整 shader 流程。

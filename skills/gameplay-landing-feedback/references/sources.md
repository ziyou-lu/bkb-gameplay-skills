# 落地事件与强度分级反馈

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 落地没有可感知接触，或贴地持续触发尘团/震动。

## 先确认的输入

真实着地事件、下降高度或接触速度、支点、坡面/平台状态与现有落地规则。

## 分步机制

1. 用同一物理轨迹录制原版，区分一次离地后的着地边沿和持续接地。
2. 在真实着地事件处组合压缩/回弹、脚边尘与向下镜头冲击；下落拉伸由运动方向驱动，支点不漂移。
3. 按高度或接触速度设置有上限的分级，小跳可轻量或不播；参数由项目验证，不从案例猜映射公式。
4. 短暂停顿或白闪是可选层，逐项对照再组合，不让每次常规小跳抢走注意力。

## 适用限制

- DerbjhXTzfy 部分画面加正文，具体高度映射、声音与落地伤害未知。
- DXZ35VuEx0e 有同物理展示，但编号不全，0.07 秒是未执行伪代码示例而非最优值；不得顺带改落地判定。

## 验收

- [ ] 斜坡、台阶、连续跳、移动平台和边缘着地不把一次接触重复当多次事件。
- [ ] 同物理 A/B 前后速度、跳高、碰撞和伤害不变；小/大落差强度有上限且可区分。
- [ ] 传送、中断、死亡和快速连续着地后视觉/镜头复位，关闭高强度层仍能读出落地。

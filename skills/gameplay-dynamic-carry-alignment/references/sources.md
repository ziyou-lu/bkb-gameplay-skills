## 工程迁移：校准与候选变换

以下为供游戏创建 Agent 实现和测试的工程方案，不是作者源码、已测试算法或来源中的公式。选择项目已有变换约定；不要求采用此特定实现。

### 先固定坐标和测量约定

1. 将几何测量放到统一单位、已处理资产缩放的物体空间。若保留非均匀缩放，先在缩放后的几何上重新测方向和距离，不能只旋转未经缩放的轴；下面公式只描述无剪切的刚体对齐。
2. 定义局部单位长轴 l，正交化后的厚度轴 t，以及 b = l × t；列向量矩阵 B = [l,t,b]。厚度轴的正方向定义为从手部接触点指向物体内部中心线。若原轴共线或长度退化，返回配置错误而不是输出 NaN。
3. 局部锚点 a 放在所选握持截面的中心线上。沿 -t 测到手侧表面的正距离 r。非圆或锚点偏心时，r 是该截面/接触方向的支撑距离，而非全物体包围盒最大半径；若已有表面锚点，不可再应用中心线半径补偿。
4. 冻结参考携带姿态，摆好参考物体，得到期望世界长轴 L、厚度方向 N 和正交基 D = [L,N,L × N]。将 D 相对携带挂点旋转保存为该姿态组的校准旋转。运行时由当前挂点重建 D，而不是沿用校准时的世界方向。
5. 手部目标 H 为已包含手模型接触偏移的世界接触点；嵌入量 d 使用项目单位并由模型遮挡容差决定。将 d 限制在项目允许范围且不超过该方向可用距离，禁止拿它修正轴符号。

### 一个可检查的候选式

在列向量、正交基及上述中心线锚点约定下：

- 物体旋转 R = D × transpose(B)。
- 目标锚点 A = H + (r - d) × N。
- 物体平移 p = A - R × a。
- 任意物体点 x 的世界位置为 R × x + p。

这样锚点变成 A，手侧表面 a - r × t 变成 H - d × N。d = 0 时表面应落在 H；这个代入检查可直接发现半径正负号错误。若项目使用行向量、不同轴顺序、父级空间或表面锚点，应先换约定，不能原样抄公式。

校准旋转和接触偏移只保存一次；每帧从当前挂点和当前有效几何重新组合最终结果，不对上一帧结果继续加偏移。附着可使用项目的父级、刚体目标或约束方式，选定唯一变换写入者；这不构成碰撞求解器或物理质量模型。

### 建议验证，不是已有实测

- 用相同姿态的两件不同 r 样本验证锚点位移差沿 N 等于半径差，而接触表面仍对齐 H；再把角色整体旋转复测，误差不应随世界朝向变化。
- 覆盖相同粗细不同长度、相同重量不同粗细、偏心截面、几何修改和非法零轴。长度改变不自动改变重量，重量数据仍来自玩法。
- 检查切割使几何版本失效、拒绝超限、取消和连续拾放后的身份与绑定清理。重量门控、缓存版本、释放位置检查、碰撞状态恢复、容差和去重均为工程守护，不是影片证实的完整生命周期。

## 与相邻技能的边界

- 工具身体协调的输入是挥动轨迹、固定握点和 rig 通道，失败关注滑握及动作相位；本技能输入是变化的物体尺寸、重量组、局部框架与锚点，失败关注尺寸相关接触距离及附着生命周期。可组合，但不互相替代。
- 掉落拾取拥有生成到权威入账的状态，成功后可回收对象；本技能携带期间保留实际世界对象，放下也不视作经济领取。

## 可选平面投影：工程推导

以下是实现起点，不是作者公开公式或已经运行的代码。只适用于一个无限几何平面；不自动获得有限地板边界、遮挡、坡面拼接或多层接收能力。

设当前蒙皮后世界顶点为 x，世界平面上一点为 p，单位法线为 n。项目提供非零投影方向 d 和正的近平行阈值 epsilon。先归一化 d，再检查 abs(dot(n, d)) > epsilon；否则隐藏或回退至已声明的有效方向，不能继续除法。沿此方向的直线与平面交点为：

q = x - d * dot(n, x - p) / dot(n, d)

可加小偏移 qVisible = q + n * bias；bias 使用项目世界长度单位并由视觉检查确定。若材质要求世界位移，输出 qVisible - x；若要求绝对位置则使用 qVisible，不能把两种接口混用。该式按直线求交，不是具有光源遮挡与可见性判定的阴影射线追踪。

更直观的艺术参数化：先取平面内单位方向 u（dot(n, u) = 0），令 h = dot(n, x - p)，以非负无量纲 stretch 表示单位高度的水平伸长：

q = x - n * h + u * h * stretch

此式保持平面上的点不移位，并使离平面越高的点沿 u 延伸。u 的方向与 stretch 对应艺术角度和长度控制，不是作者给出的参数化；不要再同时套一次方向投影而双重拉长。项目须给 stretch 上限、u 退化时的回退和接收面的适用范围。地下顶点可能反向延伸，应修复模型/接收平面或采用明确的裁剪策略，而非默默改变角色物理。

## 工程选择与验证边界

入口的骨骼映射与绑定姿势核对、更新顺序、LOD 骨骼保留、动画可见性策略、纯表现碰撞关闭、材质光照/透明/双面选择、深度偏移、额外实时投影开关、投影后 bounds、有效平面筛选与性能对照均为库侧工程建议，不声称原帖演示或验证。姿态复用避免重复动画求值的意图有正文支持，但具体引擎实现和是否仍有额外蒙皮/绘制开销要由项目验证。

本机制输入连续骨骼姿态、简化蒙皮网格和接收平面；输出持续同步的角色剪影，失败是姿态不同步、退化投影、平面错选或投影后被错误剔除。它与地面位置圆斑、事件驱动的表面余效网格不同，不能因同为“贴地”而合并。

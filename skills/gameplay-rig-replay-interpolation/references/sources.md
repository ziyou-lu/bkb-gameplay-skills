## 本库新增的可实施选择

以下是面向目标项目的工程指导，不是原作者已公开的 schema、算法或已完成代码：

- 绑定兼容骨架、稳定 ID、父关系、局部静止变换与蒙皮；选用根变换加局部旋转，并显式保留动画化平移/缩放。非均匀缩放/剪切按实际表示处理，不承诺通用重定向。
- 根据项目现有 API 选择旋转插值；在最短路径成立的区段处理四元数等价符号、有效模长及归一化。球面插值和归一化线性插值仅是可选方案，不归给作者；高阶曲线不是必需改动。
- 用原记录时间戳定位区间，分开播放控制与显示求值；定义精确端点、重复时间、大间隔、模式切换、循环及断点语义。坏样本回退从声明区段内按目标时间确定有效记录样本，而非保留最后渲染结果。
- 使用可随机访问且不依赖上一显示帧的姿态求值，按对象生命周期/复用代次、会话、片段和请求版本处理异步请求失效；关闭重复驱动，不重启玩法物理，也不因回看补发伤害、掉物或奖励。
- 提出关键姿态一致性、刚性链段长、四元数符号、快速多轴转动、全转数歧义、变速、seek/倒放和真实伸缩等验收。它们是待在项目执行的用例，不是本次已通过的引擎测试。

保持局部刚性偏移可以防止独立世界位置插值造成的结构性缩短，但不保证恢复未采样的真实旋转路径，也不自动保持脚接触、双手持握或物理约束。提高显示采样频率不会重建从未记录的整圈、接触或事件。

## Owner 边界判断

完整审阅基线的 98 个技能、101 条任务路由与 167 条来源后，没有发现已有骨骼回放姿态求值 owner。新任务的输入是带时间戳的已录制姿态及兼容 rig，状态为回放时间到有效采样区间再到最终层级姿态，主要失败是重采样变形、路径歧义、跳转不一致或误触玩法。

- motion-deformation：事件驱动有意形变并回归基准；本页不设计形变，而是避免回放意外破坏已有结构。
- secondary-motion：父运动与锚点推进装饰求解状态；本页从记录时间求值，不重新推进历史依赖模拟。
- gait-step-scheduling：移动意图与支撑状态产生选腿/髋调度；本页不根据回放姿态触发新脚步。
- tool-body-coordination：实时工具目标和持握约束生成身体姿态；本页消费已录制结果，不求新的持握解。
- skeletal-planar-shadows：消费现成最终姿态并投影副网格；本页先解决姿态重建，非阴影生成。
- landing-tumble-recovery：真实接触触发失控、掉物和恢复；本页只显示相应记录，不重放其业务后果。
- movement-feedback：实时移动方向映射方向帧并稳定边界；本页不改变方向素材或输入响应。

因此建立一个独立的 rig-replay-interpolation owner，以上入口以组合链接与双向 distinct_from 保持边界；不因同属动画而强行并入，也不另外建立录制、视频导出或渲染管线迁移技能。

与本批 airtime-trick-alignment 分开：该任务读取实时剩余飞行预测改变表现计划，本项读取历史姿态在指定时间求值。来源虽同作者，也不据此补全另一篇未披露的代码、录制时钟或物理实现。

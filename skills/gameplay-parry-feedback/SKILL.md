# 弹反窗口、成功确认与反击反馈

## 触发条件

弹反预备、失败、成功与反击机会混淆，显示窗口不符判定。

## 输入与前置条件

输入、有效窗口/时钟、攻击可弹反标记、成功/失败事件、攻击者状态及现有反击奖励规则。

## 实施步骤

1. 先显示并记录真实窗口的起止，预备姿势开始不等于有效窗口开始；调整窗口须作为玩法变更确认。
2. 预备、执行、失败、成功分别绑定真实状态；不可弹反攻击不播放成功反馈。
3. 成功瞬间组合短停顿与闪光/火花，普通格挡采用可区分表达，避免仅增加亮度造成混淆。
4. 攻击者已有失衡/击退时表现其暴露状态；没有该规则则不新增位移或硬直。
5. 只有规则允许时显示反击机会/完美层级，窗口结束撤销提示；取消、连续请求、双方死亡按状态机出口清理。

## 参数调整

反馈强度、停顿和机会提示持续期分开调；机会提示以真实过期时刻为上限，不能为看清多留一个虚假可反击窗口。

## 验收与失败处理

- [ ] 窗口前、开始、结束及之后逐边界检查真实结果与显示。
- [ ] 成功、失败、不可弹反和连续请求不误判或重复奖励。
- [ ] 攻击者恢复与反击过期正确，关闭强光仍分清结果且看得见下一招。

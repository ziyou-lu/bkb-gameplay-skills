# 踩踏反弹与连续命中确认

## 触发条件

踩头成功、主角反弹和连续踩踏层次不清，显示分数被混同为实际奖励。

## 输入与前置条件

有效踩踏事件、目标资格、接触点、真实反弹、目标状态、连击有效期/重置与确认得分。

## 实施步骤

1. 有效踩踏作为一次确认事件，同一持续接触不能逐帧重发；不可踩或失败接触沿真实规则处理。
2. 成功时组合目标压扁、接触停顿与烟团/星形冲击，各调用共享 owner，在同一接触时间点启动。
3. 主角反弹时可纵向拉伸来表达真实离地运动，形变不增加跳高；反弹规则变更必须独立实现/验收。
4. 连击层只读已确认连击数与分值，可增强层级但不得由浮字累计生成业务奖励。
5. 中断、连击过期与重开时按业务状态退出显示，清理拉伸/停顿；粒子消散不能重置真实连击。

## 参数调整

按实际反弹节奏调压扁、拉伸与浮字寿命，密集连踩先控制叠加预算。分数、连击时限、跳高不是视觉调参。

## 验收与失败处理

- [ ] 单次接触只确认一次，失败和不可踩目标不播连击成功。
- [ ] 连续不同目标/同目标重接触反弹与计分一致。
- [ ] 纯表现前后伤害、跳高和分值不变；过期/重开无冻结或浮字残留。

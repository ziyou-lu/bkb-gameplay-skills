# 踩踏反弹与连续命中确认

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 已有踩头动作，但成功接触、反弹与连续踩踏层次不清。
- 连踩时视觉重复，或显示分数/主角拉伸被混同成真实反弹和奖励规则。

## 先确认的输入

有效踩踏判定、目标是否可踩、接触点/方向、主角真实反弹事件、目标状态变更、连击有效期/重置条件与已确认分数事件。

## 分步机制

1. 将“有效踩踏接触”作为一次确认事件，不以重叠帧或粒子接触代替真实判定。失败接触走项目既有规则，不自动反弹。
2. Deuo1C7TfMW 展示目标压扁、FREEZE 接触停顿、烟团与旋转星星；分别调用形变、停顿和冲击 owner，保持接触时点一致。
3. 主角反弹时可纵向拉伸，显示实际离地运动。来源 BOUNCE 展示更高反弹，但修改目标项目跳高是玩法变化；仅调整表现时保留原轨迹。
4. 连踩奖励只订阅项目已确认的连击和结果。来源 Bonus 可见连踩三只及 +100/+200 递增，不能把这些当通用分值、连击时限或完整经济规则。
5. 连击结束、被打断或重开时，清理本次表现与显示计数；真实连击如何重置按项目规则，不由拉伸或粒子播放结束决定。

## 适用限制

- 停顿时长未知；挤压/弹簧声和音高递增来自正文，未核听。
- 画面未证明完整踩踏判定、连续计分或失败分支；状态边界和一次性处理是迁移建议。
- 本技能不负责通用落地反馈，也不把每一次普通着地当作踩踏成功。

## 验收

- [ ] 同一次接触持续多帧时只确认一次；不可踩目标和失败接触不播放成功连击。
- [ ] 连续不同目标、同目标再次接触及中断时，真实反弹与显示一致，无重复奖励。
- [ ] 纯表现调整前后跳高、伤害和分值不变；获准的机制变更另测。
- [ ] 连击结束或重开后没有残留分数层、拉伸或冻结状态。

## 组合而不复制

- [命中停顿](../../gameplay-hitstop/SKILL.md)、[冲击粒子](../../gameplay-impact-visuals/SKILL.md)、[压缩拉伸](../../gameplay-motion-deformation/SKILL.md)负责各自表现。
- [事件浮字](../../gameplay-floating-numbers/SKILL.md)仅显示已确认分数，不负责连击经济。
- [近战编排](../../gameplay-melee-feedback/SKILL.md)处理普通接触；此处拥有踩踏/反弹/连击的组合边界。

# 命中停顿与表现节奏

## 触发条件

接触瞬间不明显，或释放/翻牌等非接触节点需要短暂停顿强调节奏。

## 输入与前置条件

事件种类、当前时钟/动画速度、物理与 UI 更新策略、输入/联网约束、重复触发频率。

## 实施步骤

1. 把接触 hit-stop 绑定真实命中/落地，挥空不触发；释放或揭示停顿绑定各自确认节点，不伪造接触。
2. 选最窄影响范围：受击体、攻击动画或表现层。只有项目明确允许才改全局时间尺度，列清 UI、相机、音频和输入继续/暂停规则。
3. 以可撤销的本次停顿状态保存受影响对象原速度，结束时撤销本次贡献；不硬恢复为 1 覆盖合法慢动作。
4. 为轻击、重击和终结分别配置权重；同帧和连续命中有合并/预算策略，避免不断重置结束时刻造成永久冻结。
5. 取消、死亡和切场走统一释放路径。使用不会被自身暂停卡住的计时来源；慢动作叠加和联网状态各按项目契约验证。

## 参数调整

先从零停顿逐步增加时长，找到能读出接触但不吞节奏的最短值；接触与非接触分开调。帧数配置须明确帧率/时钟，不直接把演示帧数搬成毫秒。

## 验收与失败处理

- [ ] 接触准确且挥空不触发，非接触节点不会被识别为命中。
- [ ] 密集命中、取消、切场与慢动作重叠都恢复正确状态。
- [ ] 输入和 UI 按约定运行；关闭效果无意外判定改变，失败优先检查计时器是否被自身暂停。

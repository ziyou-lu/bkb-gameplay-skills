# 冲刺路径与残像反馈

## 触发条件

冲刺像普通位移，或厚重残像吞没角色、路径和落点。

## 输入与前置条件

真实冲刺起止、方向、速度/距离、碰撞规则、视觉层与残像生成/回收预算。

## 实施步骤

1. 固定路线和速度记录无效果基线，标出起点、方向与结束点。
2. 按需要添加方向拉伸、残像或速度线；若增加预备段会延迟输入，先作为独立玩法变更处理。
3. 残像在选定冲刺段按时间或距离生成并保留当时姿态，独立老化退出；不让旧残像继续跟随当前角色。
4. 把轻轨迹、密轨迹、幽灵样式作为替代方案比较，不叠满所有层。屏幕 FOV/模糊调用速度镜头入口。
5. 结束、碰撞打断、传送时停止生成，清理或按已定义寿命退场；恢复本次形变，不更改无敌或实际移动。

## 参数调整

分别调残像间距、透明度、寿命和最大实例数；路径缺段先看生成间距，角色看不见先减密度/寿命而不是加亮主角。

## 验收与失败处理

- [ ] 同速度同动作比较轮廓、路径、落点与遮挡。
- [ ] 连续冲刺、中断、传送没有长条桥接或缩放残留。
- [ ] 低特效仍可辨认起止；速度、距离、碰撞和无敌规则不变。

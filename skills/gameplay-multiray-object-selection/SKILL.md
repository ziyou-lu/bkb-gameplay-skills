# 圆形多射线的宽容物件选择

## 效果预览

同一小物件布局与准星轻移；右显示圆内采样，近中心合法候选单一高亮，镜头与交互结果不动。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![小物件不用死盯一个像素：使用前后对比](assets/before-after.webp)

## 触发与输入

远处可交互物在屏幕上很小，单条准星射线要求不必要的精确对准时使用。先确认任务允许扩大选择容差，而不是改变可达距离、揭示被遮挡物件或自动把镜头拉向目标。

取得实际游戏相机、有效 viewport、显示准星的逻辑锚点、可交互对象身份/资格接口、交互距离和阻挡规则。项目还需选择圆形容差的单位与大小、射线分布/数量、候选比较位置及相同分数的确定性处理。若 UI 使用偏移准星，复用[偏移交互准星](../gameplay-offset-interaction-reticle/SKILL.md)提供的锚点，不再假定屏幕中心。

## 实施顺序

1. **先保留单射线基线。** 记录当前相机到场景的转换、目标层/实体映射、最大查询距离、玩家实际交互资格与障碍物规则。选中只是焦点，提交仍经业务系统验证；远处可显示的目标不一定可操作。不能因为改成多条射线就放宽距离、穿墙或开始移动相机。
2. **在同一图像平面布样。** 将准星锚点转换到当前 viewport 的实际像素/等效坐标，以它为圆心，包含中心样本并在圆内分布其余样本。保持横纵单位一致，避免把宽高归一化坐标中的等半径误做成屏幕椭圆。半径、密度与是否按视口高度归一化由项目选择；窗口、分屏、UI 缩放或动态分辨率变化时重新核对转换。只采样有效视口内的位置，不靠钳制越界样本制造重复边缘射线。
3. **使用实际投影生成射线。** 对每个样本调用相机的屏幕/视口到射线接口，遵循透视或正交投影，不把所有射线简单平移成平行方向。查询按射线方向排序并执行既有阻挡规则：忽略明确可穿过的物件后，最近的有效阻挡若不是合格目标，该射线不贡献后方目标。过滤只保留目标层、从而漏掉墙体是错误实现；透明材质也不自动意味着可穿透。镜头贴墙、起点在碰撞体内部等场景需验证查询语义，必要时使用项目已有近裁剪/阻挡保护。
4. **按对象身份收集候选。** 将各射线的合法目标命中归并到稳定的交互对象 ID，而不是按子碰撞体复制候选。保留本帧有效命中与可见性证据，再校验实际交互距离、目标启用状态和业务资格。多个样本命中同一对象不等于更高优先级。稀疏采样不是对整圆的连续覆盖，位于样本间隙的小物体可能仍漏选。
5. **明确“最靠近中心”的度量。** 给每个候选选用同一种项目约定的屏幕比较位置，例如投影后的交互锚点，并按它到准星圆心的屏幕距离排序；锚点只是评分位置，不能替代有效射线的遮挡证据。若项目改用最近可见命中点/投影轮廓，则重新验大物体与细物体的偏好，不把两种度量混用。相同距离用稳定 ID 或既定顺序打破平局，输出一个目标。不能直接取物理返回顺序、世界最近物或最多命中者；只有证明采样顺序与所选评分等价时才可提前退出。
6. **让焦点与操作一致。** 显示/高亮从这一个选择结果读取，交互提交针对显示的同一身份并重新检查距离、遮挡和资格。快速移动、目标销毁或资格变化时清空失效焦点；不要让点击读取几帧前的缓存对象。是否保留焦点以抑制抖动需项目显式决定：滞回会改变严格的最近中心规则，不能暗加后仍声称每帧最近优先。成功/失败反馈交给[交互状态](../gameplay-contextual-ui/SKILL.md)。

## 调参与失败定位

先用中心、圆内边缘、圆外、双目标和遮挡样例确定选择规则，再调半径与样本密度，最后在目标设备测量查询开销。半径太大容易选错邻居；射线太少容易漏细目标；盲目加数量不解决投影、过滤或排序错误。记录实际每帧射线数、命中数和耗时，按预算选择批处理或更新节奏；降低更新频率后仍需在提交前做最新合法性核查。

- 穿墙选中：检查阻挡层、触发器策略、命中排序与相机起点，不用缩小容差掩盖。
- 目标在圆内却时有时无：可视化采样点与命中，区分采样空隙、子物体身份和资格变化；不要声称圆内任一点都必然命中。
- 大目标或边缘目标抢焦点：先查评分锚点/轮廓含义和同分规则，再调容差；世界距离不是屏幕中心距离。
- 准星已偏移但选择仍在正中：统一逻辑锚点与 viewport 转换，不单独挪动高亮来补错。
- 不支持当前视图或配置缺失：退回项目原单射线方案并清空辅助缓存，保留相同阻挡/提交规则，不把失败当作无条件可交互。

## 验收

- [ ] 单个小目标在采样覆盖范围内更易取得焦点，圆外与距离不符的目标不因辅助变成可操作；明确记录采样空隙和目标尺寸限制。
- [ ] 拥挤目标、大小不同目标与相同分数场景按已声明的屏幕度量选唯一对象，多个碰撞体或射线命中不提高权重。
- [ ] 实墙、可穿过物件、前后目标、贴墙镜头和目标被部分遮住时遵循既有遮挡规则，无穿墙选择。
- [ ] 移动/销毁/禁用目标及快速切换时，高亮、显示焦点与提交对象一致，没有陈旧交互；业务结果仍由权威接口决定。
- [ ] 不同画幅、viewport、正交/透视和准星偏移下采样圆与可见准星对齐；性能结论来自同配置测量，不以射线数推定成本。

只想提高目标发现性走[世界目标提示](../gameplay-world-readability/SKILL.md)；只想调整准星位置走偏移准星入口。此处不实现武器瞄准姿态、镜头吸附、伤害命中或自动操作。需要核对公开机制、作者回复和未验证实现时，读取[来源参考](references/sources.md)。

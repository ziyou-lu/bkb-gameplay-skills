## 作者说明支持的机制

作者说明 Phase Visualizer 会隐藏周围大量环境并突出重要元素。为了让声音配合这种视觉隔离，使用 Unity Mixer Snapshots，在普通游戏音频与替代混音之间混合；替代混音通过低通等混音器效果过滤许多环境声音。作者称这一方案能应对游戏中不同环境。这里记录的是作者说明，不是对其运行项目、音频设置或跨环境效果的独立测试。

观察时完整读取单帖说明。采样画面为紫色遮蔽/轮廓化世界，并出现“helps to sell the sense”字幕；另一采样画面可见橙色谜题符号与 Memory's Reach 标识。播放器音量为零，未独立核听普通与激活态的声音差异，没有编辑器设置、运行代码或性能验证。

未知项包括：低通截止频率、滤波斜率、增益、过渡时长、插值方式、总线拓扑、重要声音保留清单、具体 API 调用、多个状态的优先级，以及中断/恢复方案。不据此声称所有声音被静音、整个主混音被低通，也不把作者的跨环境表述改写为已验证的普适效果。

## 与邻近机制的区别

- `gameplay-physics-stage-audio`：输入为真实断裂、倒伏、接触阶段，输出为阶段音频实例和变体。这里输入为已存在能力的权威状态，输出为混音目标与过渡；失败重点是残留滤波、重要信号受损和混音控制竞争。
- `gameplay-foliage-rustle-response`：输入为有效植被接触及移动速度、强度和方向，输出为对象级发声响应。这里不检测接触、不创建沙沙声，也不把移动参数当作能力状态。

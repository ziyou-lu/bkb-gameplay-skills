# 来源与工程边界

## 公开材料与可支持的机制

- 来源：[DW--zsWAnAS · @100stonesinteractive](https://www.instagram.com/100stonesinteractive/reel/DW--zsWAnAS/)，作品 Memory's Reach。材料核读日期：2026-10-23。
- 作者正文说明 Translocator 原表现包含剧烈运动和屏幕扭曲，并加入可选的无障碍表现：禁用这些效果，采用简单暗角淡化和没有沿途镜头运动的传送，抵达相同目标。
- 作者说明替代模式加入与普通行进时间相应的短暂等待，保持总体完成时间；作者的明确设计意图是避免替代模式因省去旅程而获得速度优势。这里记录的是作者的时序说明与意图，不是本库测出的运行结果。
- 有限视频采样可见峡谷穿越时的明显扭曲/模糊画面，并可见“VIGNETTE FADE”字幕。样本不足以测量两模式的精确耗时，也不足以重建完整镜头、遮蔽或提交时序。
- 未披露数值延时、按距离计算旅行时间的公式、淡化时长/曲线/颜色/半径、输入锁、碰撞/物理、伤害/无敌、网络同步、重入或中断语义。未核听音频，未获得可执行源码，未运行目标游戏或引擎测试。
- 不据此承诺预防晕动症或其他症状，也不把“同目标、同完成时长”扩写为任何场景下全部玩法优势等价。评论中的电力效果、引导放置等建议不属于作者已实现的机制证据。
- 与[来源登记](../../../sources/posts.json)中的规范化 ID DW--zsWAnAS 双向关联；不复制原视频、音频或非必要个人信息。

## 新增工程决策，不是作者已披露的内部实现

执行入口为使游戏创建 Agent 能落地此机制，提出共同传送计划、单一完成门、权威提交与显示完成分离、按请求标识取消旧回调、相机/效果层所有权、渲染历史重置、设置切换和失败清理。这些是本库的实现约束与候选方案，不是对原项目源码的复述。

“已有能力一次提交”与“保留真实沿途模拟、单独冻结观察镜头”是两种需由目标项目选择的接入方案；来源没有说明原作品使用其中哪种。共享期限表达式只是计时契约，不提供旅行时间公式、游戏时钟类型或任何数值默认值。

淡化在既有预算内编排，以及没有提交后预算时省略淡入，是为防止额外增加总时长提出的工程取舍。它不代表原作品具有相同的淡入曲线、提交时点或降级方案。暂停、时间缩放、动态目标、输入/冷却语义、碰撞、失败回退和联网校验均需项目独立确认。

验收清单是待执行的目标项目测试：不同距离和动态目标的目标/完成时序比较、无镜头路径、淡化预算、模式切换、取消、重入、残留状态以及玩法规则分项核对。未声称这些案例在来源或本库中已经测试通过。

## 独立 owner 与相邻任务边界

独立 owner：gameplay-reduced-motion-teleport；任务路由：reduced-motion-teleport；唯一机制：equal-duration-reduced-motion-teleport。

独立依据不是作者或外观差异，而是不同的实施契约：输入为普通传送的权威目标与完成时长；状态为同一计划下的普通表现或静止等待/直接切换；失败包括替代模式提前完成、淡化追加时长、镜头仍飞行、取消后旧提交及恢复残留。

- traversal-transitions 的输入是边缘/抓杆进入资格和玩家停留、离开意图，输出是移动状态选择；不维护双表现共用期限。
- scene-transitions 的恢复条件是场景、出生点和镜头真实就绪；即使同样使用淡化，也不能合并为固定时长传送。跨场传送可组合其就绪门。
- dash-feedback 在已有冲刺上绘制路径和轮廓，失败重点是残像遮挡、桥接与回收；不拥有静止观察和能力时序。
- speed-camera 按真实速度驱动 FOV、模糊和边缘效果，负责强度与恢复；关闭通道可以复用，不能替代本入口的共同计划和提交控制。

上述四个路由列为 distinct_from，反向关系一并提出；没有把邻近技能的作者实现或证据移入本来源。

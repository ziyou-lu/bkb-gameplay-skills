# 向下冲刺、翻滚与动量再利用

## 触发与边界

用户明确要求向下冲刺落地后保留推进感，或翻滚中再次冲刺借用储存动量加速。本流程改变实际速度、位移和可达区域；仅要求视觉更快、落地更重时不要启用。

## 输入与前置条件

取得移动状态机、重力方向、碰撞前速度采样点、接地/支撑面判定、实际输入绑定及速度写入归属。由项目确定：允许转换的地面/坡度、翻滚输入或自动进入条件及输入窗口、前进方向来源、速度单位与参照系、映射曲线与上限、储存量含义、衰减/有效期、加速时长、退出规则和链式动作预算。不明确的规则先作为待选设计确认，不从动画猜测。

## 实施步骤

1. 建立状态路径：向下冲刺 → 合格接地且允许翻滚 → 翻滚；翻滚中有效冲刺输入且有剩余预算 → 短时加速 → 常规移动规则。无效接地、取消、死亡、传送各有退出路径。为一次下冲分配唯一转换标记，持续贴地与多接触回调不得重复结算。
2. 在碰撞求解清除法向速度之前保存入射速度及支撑面运动参照；按选定的世界或支撑相对坐标提取沿重力方向的下降分量，不把总速率、平台运动和接触后零速度混用。只有下冲状态及合格接地共同成立才允许交接。
3. 将输入/朝向投影到支撑切平面并归一化作为前进方向。投影退化时按项目规则尝试上次有效切向朝向；仍无有效方向则回退普通落地，不任意朝世界轴发射。墙面、天花板、超限坡和不允许翻滚的表面不产生速度转换或预算。
4. 用有界映射将下降速度交给翻滚的切向目标速度；明确它是替换目标还是补充现有切向速度，不能二者叠用。保持碰撞的非穿透处理，由唯一移动控制入口写入一次；不要同时施加自定义冲量又保留求解器对同一转换的额外弹射。只有成功进入翻滚才提交转换标记和储存预算。
5. 以项目定义的储存量记录本次转换可供后续冲刺使用的预算。翻滚内冲刺通过状态、输入窗口、冷却及剩余预算检查后，原子地消费一次预算并开始有时限的速度增益；持续按键、多输入回调或接触抖动不得重复消费或刷新时长。预算不是无限累计的隐形能量池。
6. 明确连招规则：哪些新下冲可以重新取得预算，当前加速是否允许续接，续接采用替换还是拒绝，以及链内总速度/持续时间上限。禁止把本次加速产生的速度再次当作免费预算循环放大；需要允许循环玩法时单独设计并验证其有限上限。
7. 加速结束撤销本次增益，通过当前移动状态重新求速度，不恢复可能过时的整段旧速度。离开翻滚、失效、取消、死亡、传送或重生按已定义生命周期清空预算和计时；不得把旧预算带入下一条无关动作链。

## 调参与失败处理

先固定方向、资格和单次结算，再调下降速度→翻滚速度曲线、翻滚可存预算、加速幅度/时长和链上限。需要具体有界映射候选时读[实现选项与来源](references/sources.md#工程实现选项非来源公式)。

- 落地瞬间归零：检查是否采样了碰撞后的速度，或普通落地分支覆盖了交接目标。
- 速度翻倍/越滚越快：检查求解器与控制器双重施力、同接触重复转换、预算重复消费及自我补充。
- 斜坡/墙面异常发射：检查支撑资格、切向投影、退化方向回退及平台参照系。
- 加速结束突跳或留速：检查增益归属和退出状态，不粗暴恢复进入时速度。

## 验收

- [ ] 记录状态、入射下降速度、切向目标、转换标记、剩余预算与增益计时；合格下冲接地只转换一次，没有无意零速停顿或双倍冲量。
- [ ] 普通落地、墙/顶碰撞、禁止坡面、无效切向和翻滚不合格均不生成预算或额外推进。
- [ ] 不同下降速度、已有前进速度、反向输入及移动平台下输出有界，方向与选定规则一致。
- [ ] 翻滚冲刺消费一次预算；长按、连点、多接触回调、低帧率不重入叠加；加速结束及取消/死亡/传送后无旧预算或增益残留。
- [ ] 用相同路线比较实际速度曲线、跳过的距离与关卡可达区域；重复链仍受所定上限约束。验收不能只看残像长度或剪辑快慢。

## 组合

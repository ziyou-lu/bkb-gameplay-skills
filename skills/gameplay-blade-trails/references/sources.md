# 剑刃轨迹采样与网格拖尾

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 已有挥剑动作，需要可读的剑刃弧线；或拖尾在转向、换招、中断后串到旧位置。
- 问题是轨迹生成与清理，不是命中后闪光、伤害或弹反状态。

## 先确认的输入

剑尖或项目选定的采样锚点、坐标空间、动作开始/结束与中断事件、显示寿命、材质坐标方向，以及独立存在的攻击碰撞判定。

## 分步机制

1. 用 DemlZDhNoFi 已核的 TRACE THE TIP 作为起点：在项目选定动作段跟踪剑尖，明确采样在世界还是局部空间。采样频率/插值由项目决定，原帖未给通用参数。
2. MAKE AN ARC：将同一次挥动的采样轨迹连接成弧。把新招式、瞬移或锚点切换视为需要检查的分段边界，不把不连续位置直接连成长条；具体重置策略是迁移建议。
3. MAKE IT A MESH：将轨迹填成可贴纹理的网格。网格拓扑、宽度与 UV 由目标引擎实现，不能将已见标题当作已核代码。
4. FADE THE TAIL：让尾部退出显示。字幕有起端 alpha 0，但起端如何对应材质坐标必须先核对，不直接照搬 UV 方向。
5. SLASH X MASK：组合斩击纹理与遮罩形成层次；在实际动画速度和背景下检查弧线，不以增加亮度掩盖采样断裂。结束或中断后按本次轨迹寿命清理，不修改命中规则。

## 适用限制

- 来源确认五个标题和对应画面，没有引擎代码、采样密度、拓扑、UV 或 shader 参数。
- 轨迹形状不证明伤害区域；挥空也可显示拖尾，真实命中仍由项目判定。
- 分段、缓存清理和异常状态检查是实施建议，不是来源已通过的测试。

## 验收

- [ ] 快慢挥动、转向和连续换招时弧线可读，不跨招串联；采样成本符合项目预算。
- [ ] 中断、角色消失/瞬移和再次启用后无旧轨迹残留。
- [ ] 材质渐隐方向正确，纹理/遮罩没有在翻转时意外反向。
- [ ] 开关拖尾不改变攻击判定，显示范围不被误当成额外可命中范围。

## 组合而不复制

- [近战命中编排](../../gameplay-melee-feedback/SKILL.md)负责真实接触之后的反馈；本技能只拥有轨迹生成与清理。

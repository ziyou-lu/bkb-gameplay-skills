# 剑刃轨迹采样与网格拖尾

## 触发条件

挥剑方向不清，或拖尾转向、换招、中断后断裂、串段。

## 输入与前置条件

剑尖采样锚点、动作有效显示段、坐标空间、材质方向、显示寿命和独立攻击判定。

## 实施步骤

1. 每次挥动分配独立轨迹段，在选定动作段记录剑尖位置；选世界空间可保留已走过的弧线，选局部空间则确认角色移动不会拖走旧采样。
2. 按时间或位移补采样并连接同一段弧线。新招式、瞬移、锚点切换时断开连接，禁止把跨段位置缝成长条。
3. 将弧线扩成可贴图网格，定义宽度方向、顶点顺序与 UV；用单色材质先查翻面、扭结和退化三角形，再加斩击纹理与遮罩。
4. 沿轨迹年龄衰减尾部 alpha，核对新端/旧端与纹理坐标一致。显示时长到期回收网格和缓存；中断可停生成并让有效旧段自然退场。
5. 拖尾只显示动作轨迹，挥空也可出现；命中仍由攻击系统确认。

## 参数调整

以最快和最慢挥动调采样间隔、最小位移和寿命；断裂先加密或插值，成本过高先限最大采样数，亮度不修复拓扑。宽度以不误导攻击范围为界。

## 验收与失败处理

- [ ] 快慢挥、反向、连续换招无跨段桥接；纹理和渐隐方向一致。
- [ ] 角色消失、传送、再次启用无旧轨迹；达到缓存上限仍可安全退场。
- [ ] 开关拖尾命中结果一致，记录目标平台顶点/实例成本。

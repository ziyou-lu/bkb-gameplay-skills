## 可选二维实现：工程推导，不是作者代码

仅用于平面内方向计算；项目需先提供同坐标系的单位面向 f、灯锚点 p、映射后的鼠标点 m、有效长度阈值及左右角界 L、R。以下约定逆时针为正，L ≤ 0 ≤ R，且 -π < L ≤ R < π；屏幕 Y 轴向下或引擎旋转符号不同时先转换。左右不必对称，具体数值由项目提供。

1. v = m - p。长度有效时，d = v / |v|；否则使用项目声明的回退，不能对零向量计算方向。
2. θ = atan2(f.x × d.y - f.y × d.x, dot(f, d))，得到面向相对的有符号角。不要直接相减两个未经环绕处理的绝对欧拉角。
3. θ 在背后跨越 ±π 时会换符号，分别限制会从一侧端点跳到另一侧。项目必须声明选择：接受有意的换边，或在背后小区域保持上次侧别，离开滞回区才换边。精确反向及首次输入没有历史时，选择固定侧或其他明确规则；不能称其为来源规则。
4. target = clamp(θ, L, R)。若采用相对角平滑，在这个受限区间内向 target 接近，而非通过区间外的最短圆弧绕行。令 a 为平滑后的相对角，再取 aFinal = clamp(a, L, R)，最终方向为 rotate(f, aFinal)。不用平滑时可直接令 a = target。
5. 使用世界方向平滑的项目，必须把平滑结果重新转为本帧面向相对角、处理背后分支并限制后再输出。面向转动和灯输出应在一致的更新阶段完成；仅限制平滑前的目标不能保证瞬时角域约束。

初始化、闲置、转身时取实际或目标面向、关闭期间的角度更新、无效投影回退，以及所有平滑与滞回参数均为项目契约。入口中的验收是库侧提出的实施检查，不是原帖或本次已执行的运行时测试。

## 独立机制边界

本机制的输入是移动面向、鼠标和开关，状态是相对照明角与启闭，失败条件是角域逸出、背后换侧抖动或通道抢写。它不重复分件姿态的素材/锚点/遮挡组织，也不重复移动观察解耦的相机控制权分离；光锥外形与阴影渲染不是该来源提供的算法。

# 射击、持续喷射与来源对齐

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 弹丸从角色/炮塔中心冒出，持续喷火近端与口部脱离，或来源主体难以辨认。
- 连续射击缺少可读发射节奏，或后坐/闪光累积掩盖了瞄准与命中。

## 先确认的输入

真实发射事件与源点、武器/角色姿态和朝向、弹丸或持续喷射的起止事件、后坐恢复规则、真实命中事件及投射物销毁条件。源点显示与碰撞系统分别核对。

## 分步机制

1. 先让源头可辨认，校对可见枪口/口部、发射姿态与弹丸起点或喷射近端。DUYNtcoiCGS 展示从物体中心改为炮口出生；DYOpA7zDmEU 展示孤立火焰改为连接红辣椒张嘴动作。它们共享来源一致性问题，不证明相同 socket 实现，也不要求设计为离体出现的法术硬接角色。
2. 在转向、翻转和不同发射姿态下分别检查视觉连接与真实出生点，再独立验墙边碰撞。外观看起来连上口部，不代表不会穿墙或伤害起点已正确。
3. 真实发射事件触发枪口光、视觉后坐和弹壳。Dekh5vBzqhG 提供组合案例，分别引用共享 owner；即使该次射击挥空也可有发射反馈，命中停顿/爆点只绑定真实命中。
4. 对连续发射检查表现是否来得及恢复。后坐是视觉还是实际瞄准变化先说清楚；纯表现不改变射速、弹道或命中规则。DVGe1E9iDdi 是三种后坐强度对照，DX_mL0Wo3vx 是有无炮侧烟尘对照，不是越强越好或必须累加。
5. 将发射、飞行/持续、命中和结束事件分开：未命中、提前销毁和停止喷射只清理对应表现，不产生成功命中；对象复用或再次开火时不沿用上一发的状态。生命周期处理是迁移建议，不是来源已核代码。

## 适用限制

- Dehz2z9Nc7F 只记录已见第 2–6 步；第 1/7 步及未保存标题未知，不补成完整射击教程。
- DYOpA7zDmEU 不证明旧系统没有发射实体，也不证明挂点算法、碰撞、伤害、射程或预警时间变化。模型制作画面不等于代码证据。
- DUYNtcoiCGS 未检查墙边穿透；后坐/烟尘无数值或单一最优方案。声音未核听，武器规则与代码未验证。

## 验收

- [ ] 不同朝向、翻转和发射姿态下起点/近端不漂移；设计应显示的源头可辨认。
- [ ] 墙边真实生成位置和碰撞单独验证，不以视觉对齐代替规则检查。
- [ ] 连续发射与停止后光、后坐和弹壳按预算恢复/清理，瞄准信息不被累积效果遮挡。
- [ ] 开枪未命中、命中、提前销毁、停止喷射和再次发射不串状态或伪造命中反馈。
- [ ] 纯表现 A/B 保持射速、弹道和实际后坐规则；实质机制变更另列验收。

## 组合而不复制

- [形变与视觉后坐](../gameplay-motion-deformation/SKILL.md)、[闪光与烟尘](../gameplay-impact-visuals/SKILL.md)、[镜头冲击](../gameplay-camera-feedback/SKILL.md)提供组件。
- [命中停顿](../gameplay-hitstop/SKILL.md)不绑定所有发射事件；[攻击预警](../gameplay-attack-readability/SKILL.md)负责危险时机可读性。
- [多阶段法术](../gameplay-projectile-spells/SKILL.md)负责蓄力、持续主体和重法术演出；本页是发射源对齐的唯一流程 owner。

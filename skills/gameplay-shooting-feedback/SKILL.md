# 射击、持续喷射与发射源对齐

## 效果预览

同一目标与瞄准方向：左侧子弹从身体中心出现，右侧从当前枪口位置发射，火光不代替弹道起点校正。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![子弹要从枪口出来：使用前后对比](assets/before-after.webp)

## 触发条件

- 弹丸从角色/炮塔中心冒出，持续喷火近端与口部脱离，或来源主体难以辨认。
- 连续射击缺少可读发射节奏，或后坐/闪光累积掩盖了瞄准与命中。

## 输入与前置条件

真实发射事件与源点、武器/角色姿态和朝向、弹丸或持续喷射的起止事件、后坐恢复规则、真实命中事件及投射物销毁条件。源点显示与碰撞系统分别核对。

## 实施步骤

1. 明确真实发射事件与源点，在武器/角色姿态中设置可见枪口或口部锚点，校对弹丸起点或持续喷射近端；有意离体出现的效果保留设计。
2. 覆盖转向、翻面和不同发射姿态，分别验证视觉连接与真实出生位置。墙边独立测试生成点和碰撞，外观接上口部不等于不会穿墙。
3. 发射事件触发枪口光、视觉后坐、烟尘和弹壳；命中反馈只读取真实命中事件，挥空仍可有发射反馈。
4. 连发按当前表现状态重触发后坐/光效并限幅，停止发射后恢复姿态。先区分视觉后坐与实际瞄准变化，纯表现不改射速、弹道或判定。
5. 分开发射、飞行/持续、命中和结束状态；未命中、提前销毁或停止喷射只结束对应表现，不伪造命中。对象复用时清除上一发的事件与效果。
6. 弹壳按独立残留寿命保留或清理，不因停火立即全部消失；累积预算由残留流程管理。

## 调参顺序

分别调后坐幅度/恢复、枪口光寿命、烟尘覆盖和弹壳生成密度。用最高设计射速检查恢复与瞄准可读性；强度由低到高比较，不把最强后坐当最佳。

## 失败处理

源点漂移先查坐标/翻面/锚点；墙边穿透查真实生成与碰撞策略；连续发射越偏越远查基准与限幅；旧发命中串到新发查对象身份及事件清理。

## 验收

- [ ] 不同朝向、翻转和发射姿态下起点/近端不漂移；设计应显示的源头可辨认。
- [ ] 墙边真实生成位置和碰撞单独验证，不以视觉对齐代替规则检查。
- [ ] 连续发射与停止后光、后坐及时恢复；弹壳按既定寿命保留或清理，而非一停火就必然消失，瞄准信息不被累积效果遮挡。
- [ ] 开枪未命中、命中、提前销毁、停止喷射和再次发射不串状态或伪造命中反馈。
- [ ] 纯表现 A/B 保持射速、弹道和实际后坐规则；实质机制变更另列验收。

## 组合与边界

- 弹壳生成绑定发射事件；需要选择短时清理或本局保留时，使用[战斗残留寿命与预算](../gameplay-impact-visuals/SKILL.md)，也不把开火残留当命中确认。

- [形变与视觉后坐](../gameplay-motion-deformation/SKILL.md)、[闪光与烟尘](../gameplay-impact-visuals/SKILL.md)、[镜头冲击](../gameplay-camera-feedback/SKILL.md)提供组件。
- [命中停顿](../gameplay-hitstop/SKILL.md)不绑定所有发射事件；[攻击预警](../gameplay-attack-readability/SKILL.md)负责危险时机可读性。
- [多阶段法术](../gameplay-projectile-spells/SKILL.md)负责蓄力、持续主体和重法术演出；本页是发射源对齐的唯一流程 owner。

需要核对案例、参数出处或证据边界时，读取[来源参考](references/sources.md)。

# 升降非对称重力与有界顶点缓降

## 触发条件

- 上升高度与节奏合适，但下落太慢，希望保留上升段而缩短下降段。
- 已有下落加速误伤上升高度、顶点反复切换、落地穿透或重力逐帧累乘。
- 需要在跳跃峰顶附近短暂放慢，且要限制滞空、禁止同一顶点反复触发；这是可选相位分支，不是默认全局慢动作。
- 若目标是轻点低跳、长按高跳，转到[可变跳跃高度](../gameplay-variable-jump-height/SKILL.md)，不要用按住状态代替下降相位。

## 输入与前置条件

重力方向和单位、向上轴、沿该轴的有符号速度、真实起跳/落地/撞顶事件、当前物理积分方式与步长、是否已有引擎自动重力、最大下降速度及碰撞检测方式。声明该规则用于普通跳跃，还是也用于走落平台、弹跳、击飞和重力翻转；水中、梯子、冲刺等运动状态先由各自控制器明确是否接管重力。

## 实施步骤

1. 固定起跳速度、上升重力和输入，记录关闭本项时的顶点高度、到顶点时间、从顶点返回同一高度的时间及落地速度。上升和下降的高度区间要一致，不拿高台起跳到低处着地的总时长代替相位比较。先独立完成下降调节，顶点缓降另开关、另记录目标高度和时序。
2. 从项目基准中独立保存上升重力与下降重力。可使用两项有单位的加速度，也可用明确基准上的无量纲相对倍率；倍率每步从基准重新求值，不能反复乘当前重力。下降更快的目标通常需要更大的向下加速度，但数值和速度上限必须由项目测试选择，不设固定通用倍率。
3. 令垂直速度为速度在向上轴上的投影，正值为上升、负值为下降。真实起跳进入上升相位；越过顶点后进入下降相位。明确零附近的判定与更新顺序：可用速度符号直接切换，或用小的项目容差及相位锁存避免数值抖动；容差带内仍施加既定重力，不创建无限滞空。进入下降后不能仅因数值噪声返回上升。
4. 对声明支持的特殊入口单独写规则：走落平台且没有真实起跳时进入下降，不能等待永远不会到来的起跳事件；正中撞顶结束上升后按碰撞结果进入下降。新合法空中跳、弹跳或足够大的外部上推若在支持范围内，显式重新判定相位；不能让旧下降锁存继续压制新上升。方向变化时重新定义投影与状态，不沿用旧轴符号。
5. 在每个物理步仅选一套相位重力，再积分一次。若引擎已经施加基准重力，要么统一改其重力系数，要么仅补目标值与基准值之差；不要自动重力和整份手动重力并行。保持水平分量和原有起跳许可不变。可选顶点分支按下节临时选择局部加速度，不另加一套积分器。
6. 明确最大下降速度是在何时限幅，并在移动后处理真实碰撞。提高下降速度前检查单步位移与最薄可碰撞平台的关系，使用项目支持的扫掠/连续碰撞或适当子步，不能靠动画或地面吸附掩盖穿透。
7. 落地、中断或进入其他运动模式时结束/转交相位状态，恢复该模式的重力设置。与[可变跳跃高度](../gameplay-variable-jump-height/SKILL.md)组合时由同一更新选择相位重力并处理截速/保持助力，分别记录两者贡献，不把按键松开本身定义为已经下降。

## 可选分支：有界顶点缓降

只在项目需要峰顶附近放慢时启用。以下采用局部加速度调节作为项目实现选择，不修改全局时间缩放，也不重放起跳冲量。

1. 在正常上升已建立、速度首次进入项目定义的近零垂速带时，允许该次跳跃进入一次顶点状态。给出速度带单位、进入条件、最长持续时间及允许的额外高度；走落平台的初始零速度、撞顶后停速和不支持的击飞不能误触发。
2. 在顶点状态暂时选择较小但仍朝下的正值重力幅度，不把垂直速度强制锁为零。保持水平运动和其他对象的更新时钟不变；若同时存在保持助力，明确顶点期间是否关闭该助力，防止两者相抵形成悬停。
3. 垂速离开允许带、时间预算耗尽、撞顶/落地或控制中断时退出，恢复当前升降相位应有的重力。预算不得被近零抖动或重按刷新；同一次跳跃不得再次进入，只有新的受支持真实起跳才能重置资格。
4. 单独记录开关该分支后的顶点高度、顶点附近停留时间和可达平台变化。它可能同时改变到顶点时间与高度，需按项目目标接受，不能继续声称仅缩短下降且完全保留上升轨迹。

## 可选分支：长落差的下降速度上限

当持续加速让下方平台来不及识别时，可只为声明支持的普通下降设置正的最大下落速率。它限制终端速度，不要求改小上升重力或使用全局慢动作。

1. 明确上限单位与适用状态：普通下落、走落平台是否共用；击飞、下冲、弹射等由各自规则决定是否豁免。不要用普通下落上限意外抹掉已经设计的冲刺速度。
2. 用单位向上轴 u 分解当前速度：vUp = dot(v,u)，切向分量为 v - vUp*u。对属于本规则的下降，仅令 vUp 不低于 -maxFallSpeed，再与原切向分量重组；上升分量不受影响。不能直接限制整个速度向量的长度，否则水平移动也会被压慢。
3. 在同一物理步完成既定加速度/适用外力后、执行实际位移前做限幅，并检查引擎后续步骤不会再加一次重力绕过上限。若引擎管理速度与积分，接入其等价阶段，不另外创建积分器。碰撞后的速度继续服从碰撞解算，不能为维持上限重新注入向下速度。
4. 从不同高度落下，记录加速段与封顶段，并在可见平台/障碍前测试识别和输入反应；同输入在匹配时刻/运动状态比较水平速度与控制响应应不变，上升轨迹不受该下降限幅直接影响。下降时间变长可增加总水平行程，必须单独测试；上限降低也可能改变落地伤害或关卡可达性，需明确接受而不是当成纯视觉润色。负值调试读数只表示轴向约定，不直接作为参数。

## 调参顺序

先关闭顶点缓降并锁住上升段，逐步调整下降加速度以达到目标下降时间；再核对落地速度、碰撞可靠性与允许的速度上限。若终端速度限制让增加重力不再明显缩短下降，检查速度曲线而非继续加大倍率。顶点缓降另调进入速度带、局部加速度与最长预算，不用扩大容差掩盖相位错误。最后测试长落差、低顶和移动平台，确认没有未经认可的关卡可达性或落地伤害变化。

## 失败处理

- 仅开启下降调节却改变顶点高度：查下降相位是否提前进入、符号是否倒置、整份重力是否重复积分；先恢复独立上升基线。
- 顶点抖动或悬停：查容差带是否漏施重力、相位是否因每步微小符号变化反复切换。
- 顶点缓降无限续期：查一次进入锁存、计时时钟与退出条件；先禁用该分支，恢复正常相位重力，不能以全局时间缩放修补。
- 下落越久重力越大：查是否对当前值累乘，改为从不可变基准计算。
- 空中跳/弹跳异常沉重：查新上升事件是否重置相位；不能用重新授予跳跃次数补偿。
- 高速落地穿透或伤害意外变大：先降低目标下降速度并修复扫掠、步长或速度依赖规则，不能扩大平台碰撞体作为默认修复。

## 验收

- [ ] 关闭可变高度控制及可选顶点缓降、保持同一初始条件时，仅开启下降调节不在声明容差外改变顶点高度或到顶点时间；返回同一高度的下降时间达到目标。
- [ ] 顶点附近相位与加速度日志没有反复切换或无重力停留；倍率不会随在空中停留的步数累积。
- [ ] 走落平台、正中撞顶和新合法空中跳按各自规则进入正确相位；支持的弹跳/击飞/方向变化不会残留旧相位。
- [ ] 不同物理步长、长落差、薄平台、斜坡和支持的移动平台下没有穿透；最高下降速度和速度相关着地效果符合项目规则。
- [ ] 接地、暂停恢复、死亡/传送及运动模式切换后重力所有权清楚，不泄漏下降倍率；输入按住与松开不单独改变本项相位。
- [ ] 顶点缓降单独启用时，近零停留时间和新增高度有界；同一跳跃反复进入速度带或重按均不续期，时间上限、撞顶、落地和中断可靠退出；水平速度、其他对象和全局时钟不被放慢。

## 组合与边界

- [可变跳跃高度](../gameplay-variable-jump-height/SKILL.md)由保持/松开改变已发生跳跃的上升段；本项由运动相位改变加速度。
- [离地宽限](../gameplay-jump-forgiveness/SKILL.md)与[跳跃输入缓冲](../gameplay-jump-input-buffer/SKILL.md)管理许可/命令，不拥有重力数值。
- [顶角纠偏](../gameplay-ceiling-corner-correction/SKILL.md)决定接触是否成功避开；本项服从最终碰撞结果，不自行穿过天花板。
- [事件形变](../gameplay-motion-deformation/SKILL.md)与[落地反馈](../gameplay-landing-feedback/SKILL.md)可以表现速度变化，但不替代真实加速度和碰撞验收。

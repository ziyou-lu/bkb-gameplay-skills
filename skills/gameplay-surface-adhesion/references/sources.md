# 来源与历史研究记录

本页仅供核对出处、参数来源和证据边界；不是执行入口。下列为改写前的研究记录，包含当时提出但未执行的迁移建议。当前实施步骤以 [SKILL.md](../SKILL.md) 为准；原始观察与验证状态以 [来源登记](../../../sources/posts.json) 为准。不得将历史建议、可见代码或作者说明当作已运行结果。

# 窄边缘攀附的支撑估计

本入口从有限 debug 与作者说明提炼附着支撑诊断，不是已运行的攀爬算法。来源中的平均命中及位姿插值是作者描述；以下缺失/冲突处理和回归检查为目标项目实施建议。

## 触发条件

- 攀爬经过很小凸缘或内外转角时，现有查询覆盖不足、支撑估计丢失或附着姿态不连续。
- 多个附近表面都被采样，位置/法线汇总与角色贴附结果不一致，需要定位采样、归属和更新问题。

## 先确认的输入

当前附着/离开状态、允许攀附的表面、有效命中位置与法线、当前角色位姿、已有探针和更新时钟。明确被更新的是视觉节点还是承担碰撞的主体，以及位姿与移动控制/碰撞的契约；来源没有公开这层分工。额外确认支撑偏移、失去支撑的处理和项目允许的表面切换范围。

## 分步机制

1. 固定路线复现窄边/转角，显示每条探测、有效命中和当前选取的支撑。先区分没有覆盖到边缘、汇总到不相关表面或位姿更新出了问题，不先任意加大吸附距离。
2. 必要时补充探测覆盖。DQChm_aD__T 作者增加 hook rays 以抓住小凸缘；实见多条绿线、直角示意与附着结果，但探针数量、顺序、起点和分支未知，不从线条图推具体递归/折射实现，也不把 hook 当物理关节。
3. 对有效且属于合理支撑候选的命中组织位置与法线估计。作者称所有射线贡献平均 hit position / hit normal；权重、剔除、法线归一化及实际公式未核。项目应单独检查不同表面归属、相反法线与离群命中，不能把无条件平均任意几何当通用算法。
4. 让支撑估计驱动已声明的角色位置/朝向更新。作者说明随时间插值，未给类型、速率或支撑偏移；选择项目实现后检查碰撞与输入契约，避免只让网格平滑贴墙却误称真实附着正确。
5. 明确暂时无命中、支撑失效/移动或主动离开的状态处理。保持上次支撑、重试、脱离等是待项目决策，不是来源已证回退；不要把过期命中一直当有效支撑或无条件吸到另一块表面。
6. 分别验收空间覆盖、估计稳定、位姿响应和碰撞安全，再比较原方案。新增射线与插值不能替代对真正缺失支撑和玩法允许范围的判断，成本也须测量。

## 来源与适用限制

- 作者报告较早相机更新影响了攀爬，并以 hook rays 修小凸缘问题。实见多绿虚线 debug、多个表面旁贴附姿态、竖直浅色边旁的角色，以及水平/垂直线的直角探测示意；这些不是旧新同输入 A/B 或全程连续过渡验证。
- 平均命中位置/法线及角色位姿插值来自作者说明，未读/运行代码。具体射线数量、起点/方向/长度、层过滤、权重、离群处理、归一化、插值速率、偏移、无命中回退及更新频率未知。
- 贴住表面的画面不证明真实物理关节、碰撞体贴合、任意速度稳定或所有表面都可攀附；作者愿望不作为全表面验证。无性能、同步输入或音频核听。
- 本页不是相机遮挡/地面识别，也不改变目标检测或提供玩家输入映射；吸附范围和位姿若影响实际移动，必须当控制/碰撞规则验收，不能包装为纯视觉优化。

## 验收

- [ ] 复测窄凸缘、内/外角、曲面与项目允许的不同厚度，记录有效命中覆盖、选取位置/法线与实际附着结果，不能只凭 debug 线多认定可靠。
- [ ] 对不同物体、相反法线、孤立/离群点、零有效命中及暂时缺失明确处理，估计不突然跳到无关或不可攀附表面；候选汇总规则有可解释记录。
- [ ] 快慢移动、快速反向和表面切换时，位姿更新无项目不可接受的跳变、穿入或滞后；明确视觉与碰撞主体是否一致，不伪造物理稳定证明。
- [ ] 主动脱离、支撑移动/销毁、传送和切场后不残留旧支撑；失败/回退不把角色无限吸住或越过不允许的间隙。
- [ ] 与原方案同条件对比命中覆盖、错误附着和开销；输入/相机变化分开检查，未测前不宣称射线越多越好或全部表面已解决。

## 组合而不复制

- [移动接触表示](../../gameplay-locomotion-contacts/SKILL.md)共享“采样覆盖需匹配接触任务”的检查原则；轮胎体积接触不是这里的位置/法线支撑估计流程。
- [接触响应诊断](../../gameplay-contact-response/SKILL.md)区分网格视觉与真实接触，不用局部穿入掩盖支撑失效。
- [顶角宽容](../../gameplay-ceiling-corner-correction/SKILL.md)在上升碰撞时做受限位置修正，不持续求攀附支撑。
- [角色遮挡显露](../../gameplay-occlusion-reveal/SKILL.md)将查询聚合成显示触发，不提供附着位姿。
- [表面相机 up](../../gameplay-surface-camera-up/SKILL.md)用表面证据控制镜头参考，不与本页共享角色附着状态或反推其算法。

- [可变形承载面](../../gameplay-deformable-support/SKILL.md)构建会弯曲/压缩的支撑物，本页估计攀爬角色如何附着，不改变承载物结构。
- [移动交互状态](../../gameplay-traversal-transitions/SKILL.md)决定停留/释放/接续选择，不替代本页几何支撑估计。

# 结果总分递增计数

## 触发与输入

用于结算界面逐步展示已确认总分，或跳过/重开后显示错误。取得权威结果 ID 与终值、显示初值、完成/失败状态、UI 生命周期及项目是否支持跳过。

## 实施流程

1. 在结果确认时保存只读目标，真实计分/发奖先完成。计数刷新不得再次累计业务值。
2. 从显示初值向终值插值并按显示规则取整；以进度结束时直接赋准确终值，避免逐次加小量造成累计误差。
3. 若有完成文字逐字效果，独立驱动但与结果页生命周期一致，不能以文字结束判定胜利。
4. 支持跳过时停止计数并立即显示终值；重复打开读取同一结果，不重新结算。
5. 离开或换结果时取消旧动画，校验结果 ID，防止上一轮的延迟回调覆盖新结果。

## 调参

分别调总时长与速度曲线，用小分数、大分数、零和项目支持的负数检查。大分数不必逐个整数播放；结束时保留足够阅读时间，减少动效可直接展示终值。

## 验收与失败处理

- 正常结束、跳过、重复打开最终都等于同一权威结果。
- 动画重放不重复计分/发奖，中断无旧计数或文字残留。
- 新结果到达后旧回调无权写入；终值不符先查目标绑定/取整，不改实际奖励。

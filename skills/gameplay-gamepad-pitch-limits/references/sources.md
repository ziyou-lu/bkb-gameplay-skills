## 新增工程决策，不是作者已公开算法

执行入口将手柄角速度和鼠标采样位移分路、限定单一合法俯仰状态、即时取消离界方向的减速、保留硬夹、丢弃越界输入积累，以及处理切换/失焦/控制权交接。这些是实现该任务时的约束与验收建议，不是对源项目内部实现的描述，也未声称已通过目标引擎实测。

以下仅为可选的无历史候选公式，不能标记为作者公式或默认参数：

- 在上为正的标量坐标中，用当前俯仰 p、上下限 lo/hi、手柄普通角速度 v，以及方向对应的正带宽 b。
- v > 0 时剩余距离 d = hi - p；v < 0 时 d = p - lo；v = 0 时增量为 0。
- 非零输入可选 g = clamp(d / b, 0, 1)，以 v × g 推进。上下侧各用自己的 b，且两带不重叠。曲线可换成有界单调映射，但必须保持入口增益 1、边界增益 0，不引入离界历史拖尾。这里的 0/1 是归一化端点，不是来源给出的游戏参数。
- 线性距离增益用粗时间步直接 Euler 积分可能撞到硬限位；须在缓动带入口拆步或使用经过项目误差验证的子步/解析积分，最终仍硬夹。渐近收敛不保证有限时间内恰好抵达端点；容差吸附须独立设计并测跳变，不能以未说明的数字补齐。
- 鼠标仅按既有位移映射后硬夹，不使用 g；不要将已累计的鼠标位移再次乘时间步。

此候选不规定任何限位角、带宽、灵敏度、角速度或容差默认值。方向、单位、时间源与更新顺序由目标项目确认。

## 独立 owner 边界

本任务以设备输入和当前俯仰到合法边界的距离触发，更新受限观察状态，失败表现是撞停、离界迟滞、越界、鼠标映射变化或设备切换残留。

- gameplay-camera-feedback 以击打/爆炸等事件驱动临时偏移并归零；其触发、状态与漂移验收不同，不能把本页合成 camera-shake。
- gameplay-speed-camera 以真实速度驱动 FOV/边缘效果并恢复；不是观察输入响应。
- gameplay-surface-camera-up 用局部表面法线确定基础 up；本页在已有 up 契约内限制玩家俯仰，不选地面/墙面参考。

独立路由 gamepad-pitch-limits；上述三个路由记录为 distinct_from。范围之外的全局鼠标平滑、yaw 重设计、相机碰撞、表面方向选择不由本 owner 接管。

# 压缩拉伸与次级运动

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 接触、弹跳或移动像刚体平移，缺少受力方向。
- 表现层形变误改碰撞体、或跟随物出现跳变。
- 车体等已显示凹陷，但碰撞响应仍像刚硬物体，需要定位是视觉问题还是有意改变接触行为。
- 持枪方向变化时角色像整张纸片旋转，肩部/上衣外形与实际瞄准姿态不协调。
- 快速转身/出招的关键姿态轮廓不清，或过渡形变掩盖了实际攻击方向。
- 输入后看起来迟迟不响应，但整段动画加速又让动作失去重量；先定位具体相位，不直接套用整体倍速。

## 先确认的输入

原始姿势/缩放、受力方向、着地点或持握点、碰撞体是否继承缩放、当前动画混合方式；做瞄准姿态时另确认真实瞄准方向、可用分件与方向 sprite，以及持握锚点和绘制层级；做快速动作时确认输入接收、首个可见响应、关键姿态、实际命中/开火、恢复事件和过渡/收尾相位，并说明哪些准备段承担玩法规则或对手反应窗口。评估物理接触时另记录入射速度/方向、接触对象和碰撞后状态，先明确是否允许改变物理规则。

## 分步机制

1. 选定视觉子节点或独立表现层，先确认缩放不会无意改变碰撞盒、移动距离或伤害。视觉网格损伤与物理响应应分别对照：DcCFXGItxdJ 展示车体已变形但碰撞仍硬，作者再以允许少量接触穿入近似金属弹性。它说明仅改外观未必匹配材质感，不是通用穿模方案。若项目明确要改变接触响应，另建局部、可回退的物理实验并与原版同条件比较；不能悄然放宽全局碰撞容差，也不能把这种变化归为同物理视觉优化。
2. 以接触/固定点为支点压缩；离开接触或加速时沿运动方向拉伸，随后回到基准姿态。上压下扁只是例子，不是所有材质规律。
3. 为预备、冲击、回弹设可识别相位；先确认必要的关键姿态，避免为了展示丰富而堆积动作。DP3HI8yjFUS 作者反思旧版帧数过多，正面枪击对照可见旧版额外持枪过程与新版伸臂射击/枪闪/回立姿。可据此提出删减不传达操作信息的表演，再检查是否还需要回弹或少量 overshoot；这不是已测输入延迟改善，也不意味着一律删除蓄力、预警或玩法要求的前后摇。DeuiO0UjRLM 进一步对比了整段加速和移除准备段的教学示意：当输入后的准备仅是冗余表演时，可先局部压缩它，再比较主体动作与收势是否保留重量，而非一起倍速播放。先区分可见响应和真实命中时刻；如改动触及真实攻击生效、取消或恢复规则，单列为玩法变更。敌人可读预兆和蓄力本身构成玩法时，不沿用删准备段结论。
4. 快速出招先保证关键姿态的方向与轮廓，再选择性用 smear 连接过渡并回收到可读姿态。DP53MiuDIpH 的 OLD/NEW 对照可见更展开的反身双臂、躯干/武器横向拉伸过渡与立姿收尾；这是观察到的差异，不是作者四步教程。迁移时应固定美术与真实动作时序，分别比较姿态和 smear，避免把更大轮廓当成更快开火或更大命中范围。枪口烟另属射击余效，不把细灰烟线误当动作轨迹。
5. 武器后坐以枪口/持握锚点合理偏移，比较不同强度；装饰跟随以父节点驱动和受控滞后表现，不延迟真实角色朝向。
6. 头发/链状装饰可参考 DbS8p3VuhkL 的锚点、距离约束和弹簧/阻尼，节点数按项目需要。传送、转向翻面和帧率变化时重置或稳定积分。
7. 若整张 sprite 无法覆盖瞄准姿态，可按头/躯干/手臂/腿/武器分件组合。CW0Su7-sy5- 展示了分件组合、部件上下呼吸、瞄准时头/身前后位移，以及按方向换上衣 sprite 四项改进。迁移时先确认静止组合和持握关系，再叠加呼吸与姿态位移，最后检查是否需要方向 sprite 修正肩部外形；位移幅度、换图边界及层级按项目决定，不从视频猜数值。这是表现组织，不是新增自动瞄准或改变射击方向的理由。
8. 俯视瞄准可按部件混用表示，而不是所有部件强行整图旋转：CW8BHbmsy_r 以普通方向 sprite 表示腿/头/眼睛，以 stack 表示躯干。它与前例的部件位移、按方向换上衣是不同分支，不拼成同一教程。迁移时先逐件对照方向外形，再检查组合锚点与前后遮挡；方向帧选择和堆叠层数/间距按项目验证，不从 8 格素材推断通用角度阈值或真实 3D 实现。
9. 复位时回到保存的基础姿态；处理取消、死亡、重复触发与动画混合，避免比例或弹簧速度无限叠加。

- 踩头中“更高反弹”可能是玩法变化；仅做视觉优化时不能未经说明改跳高。

## 验收

- [ ] 形变开关 A/B 下碰撞和操作目标保持一致，任何预期玩法变化单列；弹球等物理场景使用相同初始条件比较接触位置和反弹轨迹，不能只比较外观。
- [ ] 如有意修改物理接触，保持初始速度、角度与接触对象一致，分别开关网格形变和接触方案；检查薄障碍、高速、擦碰与重复碰撞中是否出现非预期穿透、陷入/卡住、弹飞，以及无关物体是否受影响。仅有凹陷或局部穿入画面不算稳定性验收通过。
- [ ] 转身、连续落地、传送、打断后无反向翻折和残留缩放。
- [ ] 强度与速度/高度的映射有上限，小事件不会像终结技。
- [ ] 动作删减前后分别记录输入触发、真实开火与恢复时刻，检查关键姿态和必要预警仍可读；纯表现优化不擅自跳过冷却/前后摇或改变射击频率，不以“看起来更利落”代替时序测量。
- [ ] 对响应问题分别比较原版、只压缩冗余准备段与整段加速；独立记录首个可见响应、真实攻击生效与恢复时刻，检查主体/收势的可读性和重量，不把作者一帧示意当测量结论。敌人预警、蓄力和反制窗口未因追求响应被误删。
- [ ] 用相同美术/动作时序分别开关姿态放大与 smear，检查快速过渡和收尾仍能辨认武器朝向；真实开火、受击范围和恢复时刻不被外形拉伸误导，打断后无残留拉长姿态。
- [ ] 混合方向帧/stack 表示时，绕角色一周检查头、眼睛、腿、躯干与武器朝向关系；帧切换前后锚点和遮挡不跳变，显示瞄准与真实开火方向一致。
- [ ] 在上/下瞄准、左右翻面和换图边界附近检查肩部/手臂接缝、持握点及绘制层级；呼吸与姿态位移不无意改变实际射击/碰撞。中断和快速切向后不会残留错误上衣 sprite。

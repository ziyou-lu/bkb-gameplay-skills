# 稀疏环境序列帧粒子

## 触发条件

场景背景缺少细小运动，需要在树洞等指定位置间歇出现短动画；或已有环境 flipbook 出现切格错误、末帧跳闪、同步刷屏和实例堆积。目标是装饰性环境节奏，不增加注视追踪、AI、交互或危险判定。

## 输入与前置条件

准备按播放顺序排列的手绘帧、有效帧数 N、贴图集列数 C 与行数 R、格子尺寸与索引约定；确认目标引擎的 SubUV/flipbook 接口能否限制有效帧范围。另需播放时长或每帧停留时间、单次/循环意图、粒子寿命、允许生成的场景点、背景与相机条件、生成间隔方案、同时可见数量上限和卸载/重开清理责任。参数未定时先做一个场景点的可调原型，不以整张贴图的格子数代替有效动画帧数。

## 实施步骤

1. **整理手绘帧。** 为同一短动作统一画布、透明边界和视觉锚点，避免眼睛等图形每帧无意漂移。选定起始、结束姿势，明确动画如何出现和消失；不要仅靠销毁粒子掩盖不合适的末帧。
2. **固定贴图集契约。** 将帧装入 C×R 等尺寸格子，要求 N、C、R 为正整数且 N≤C×R。记录首格位置、行推进方向以及有效帧列表；可用连续格索引，或在资产顺序不连续时显式重映射。若接口只能播放整张格表，则重新打包或按设计填充空格，不能让未使用格随机进入播放。检查格边采样/过滤是否串到相邻帧，必要时加边缘留白并调整每格采样区域。
3. **同步 SubUV 配置。** 让材质/粒子端的横纵格数与实际贴图一致，不凭参数名称猜测其接收的是总格数还是横纵维度。先禁用自动推进，分别显示第 0 帧、第 N−1 帧和每次换行两侧的帧；用临时编号格核对索引顺序，再接回正式素材。手绘离散帧先采用逐格切换；仅在目标外观需要且无重影时使用帧间混合。
4. **把播放和寿命分开决定。** 时间参数先验证为有限正值，间隔也不能为零或负数；等时帧可设每帧停留 Δt，使一次播放时长 T=N×Δt；单次播放用年龄映射并夹紧到 0…N−1，确保最后一帧有可见停留后再回收。若寿命 L>T，明确余下时间保持末帧还是淡出；若 L<T，明确是否允许截断，否则调整二者。循环播放则按 T 回绕，同时仍设置有限寿命或明确停止条件，并检查末帧到首帧的接缝。变时帧用累计时间表推进，不混用等时帧公式。
5. **先选位置，再排间隔。** 从允许的背景锚点生成，限制朝向、尺寸和出现范围，使动画留在洞口/背景区域，不穿出树体或移到角色、交互物、危险提示前。先用可复现的错时表验证节奏；项目需要变化时才选择有界抖动或其他调度，不默认随机分布。记录每个点下一次出现的时间，以及暂停、隐藏区域或重新进入时是跳过过期事件还是重新排期，避免补发积压导致齐爆。
6. **限制重叠。** 用寿命和最短间隔检查密度：固定单点间隔 I 时，L/I 可估计常态占用，实际峰值仍需结合边界同时生成/销毁与多点相位检查。设置全局及必要的局部在场上限，达到上限时明确跳过或推迟装饰实例，不无限排队。先调间隔和寿命，再调点位数量、尺寸和对比，不靠降低帧率解决生成过密。
7. **回收完整状态。** 播放结束、场景卸载、重开或功能关闭时回收实例，并取消对应生成任务。池化复用时重置年龄、帧索引、透明度和锚点；恢复时按既定排期启动，避免沿用旧末帧或重复定时器。

## 验收与故障定位

- [ ] 单实例慢速播放：首帧、换行边界、末帧与约定顺序一致，无空格闪现、串格、锚点抖动；换贴图后仍同步更新格数与有效帧范围。
- [ ] 单次能完整结束，循环接缝符合设计；延长/缩短寿命不会意外加速、截断或永久冻结，池化复用从正确起始状态开始。
- [ ] 在代表性明暗背景及实际游戏视距查看：运动可感知但不抢角色/目标/危险提示，离开允许区域不生成；装饰不被误读为可交互对象或攻击预警。
- [ ] 多点最密排期、长寿命和反复进出区域下，记录峰值实例数及实际渲染/更新成本；上限有效，无同步补发或积压。常态稀疏画面不能代替峰值测试。
- [ ] 结束、关闭、卸载与重开后无残余实例和后台生成；重新启用只启动一套排期。

串格先查 C/R、有效帧映射与采样边界；末尾跳闪查夹紧/取模和回收顺序；同一时刻出现过多查各点相位与积压补发；背景太显眼先移位/缩小/降对比，再减少数量。不得通过删除关键玩法提示来给装饰腾空间。

# 工具动作与身体持握协调

## 触发与输入

用于第一人称工具只见手动，或双手、工具和身体脱节。取得工具轨迹、双手握点、可控 rig 通道、目标高度/距离、视角约束及真实工具事件；方向 sprite 错误改走[分件瞄准](../gameplay-aim-pose/SKILL.md)。

## 实施流程

1. 记录同一挥动的手部基线，区分滑握、工具路径、身体参与与镜头问题。调试视图同时显示工具、握点和相关关节。
2. 先确定工具路径和双手局部握点，再用项目已有 IK/动画约束让手跟随；检查可达范围与肘部方向，避免工具与双手互相驱动形成循环。
3. 按动作需要逐项加入脊柱旋转、膝屈伸或头姿态，明确每通道的最终写入者；它们是可选参与，不是必须全开。
4. 让身体参与与工具动作相位协调，测试不同目标高低/远近。视觉刀刃接触与权威命中/切断分别验证，不为贴合演出扩大判定。
5. 单独限制头部与实际相机耦合，保留观察控制。头部 roll 不必传给相机；根据舒适度提供减弱或关闭方案。
6. 重复挥动、反向、取消和目标变化时从当前姿态过渡或回归基础姿态，清理旧约束权重；无效目标不保留悬空握点。

## 调参

按工具路径→握点/约束权重→身体幅度→视角幅度的顺序调，避免同时改全部通道。限制不可达动作而不是无限拉伸手臂；身体参与不足先检查相位和驱动冲突，不只增大角度。

## 验收与失败处理

- 全动作范围双手持握无不可接受滑动、穿插或交叉；高低/远近目标仍符合约束。
- 重复、反向、取消及姿态切换后驱动不争用，无残留姿态。
- 相机不妨碍观察/瞄准，原伤害、范围和频率不变；不可见身体部位用调试视图检查。
- 求解失效时按项目回退动画/约束，不让无效目标破坏整个 rig。

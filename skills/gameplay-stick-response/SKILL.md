# 模拟摇杆的静态响应曲线

## 触发与边界

适用于模拟摇杆控制的观察或移动：希望把更多物理行程用于慢速微调，同时保留边缘的大幅响应。这里修改的是“本次杆量到本次命令”的映射，不是时间平滑、按住加速、车辆辅助、相机限位或移动朝向规则。先确认项目允许改变该输入通道的响应；只需要动画变慢或限制相机角度时不要改杆量。

## 输入与前置条件

- 项目输入适配器提供的有限二维杆量、轴符号、实际量程及校准方式；核对设备/API 是否已做死区、归一化、响应曲线或平滑。不要假定硬件各方向天然线性、都能达到满量程，或中立读数恰好为零。
- 通道用途及现有消费者：观察角速度或移动目标命令、最大速度/灵敏度、时间单位、坐标转换、控制权限和设备仲裁。移动消费者若会将任意非零输入归一化，必须先改成保留幅值的接口，否则曲线无法提供慢速移动。
- 选择径向还是逐轴处理。径向适合保留二维方向、按离中心距离控制强度；逐轴适合项目明确要求两轴独立，但会改变部分斜向方向和合成幅值。两者不能叠加为不知来源的双重曲线。
- 经设备实测选定的死区及外缘校准策略、可回退的线性映射配置。没有可信的杆量域或消费者单位时，先做输入读数可视化，不猜死区数字、指数或最大速度。

## 实施流程

1. 沿输入管线记录原始/校准杆量、死区后杆量、曲线输出和最终命令。固定最大速度、灵敏度及下游控制，记录线性基线；先关掉本次新增的时间滤波或加速，既有控制器加速度另列，避免把物理响应误当曲线。
2. 明确唯一处理顺序：设备校准与已声明的量程映射 → 一次死区处理 → 静态曲线 → 通道增益/坐标转换 → 既有消费者。输入框架已经完成其中某步就复用结果，不重复截死区、重映射或归一化。死区层已将有效行程重新铺到 0–1 时，曲线直接消费该幅值。
3. 径向方案从校准向量 s 求实际长度和方向；零长度直接输出零，不做除法。先把有效长度限制到约定单位圆，死区内归零，死区外的剩余行程连续重映射到 0–1。对该标量只应用一次 f，再乘回原方向。不要先把所有非零向量归一化，或在最后把小输出重新归一化成满杆。对超过单位圆的斜向输入，应保留原方向后饱和长度，不能用夹紧后的长度作除数而产生超单位输出。
4. 逐轴方案只在项目选定时使用：每轴取绝对值，完成该轴的一次死区/行程处理，再用对应 f，最后恢复符号与既有反转设置。分别声明两轴参数及斜向合成上限；移动场景如需限制总长，只裁剪超过上限的向量，不能归一化全部非零输入。先比较斜向方向变化是否可接受，不宣称逐轴与径向等价。
5. 选用连续、有限、有界且单调不减的曲线，固定 f(0)=0、f(1)=1；在需要精细控制的低/中杆区降低输出，保留边缘最大值。可从线性与幂曲线的对照开始，或使用受约束的查找表；自定义插值不能在控制点间过冲、倒退或在死区出口跳变。曲线与参数均是项目选择，不追求某个半杆输出数值。
6. 将结果接回已有通道。观察输出若是角速度，只由观察控制器积分一次时间步；移动目标命令按原控制器规则消费，不额外乘一次时间步，也不直接覆盖碰撞/外力速度。鼠标位移、键盘离散输入、UI 方向重复节奏不自动套此曲线。俯仰限位缓动若需要，放在已转换角速度之后按当前角度独立处理，保留两层日志。
7. 同一有效输入和配置必须立即得到同一输出，不读取按住时长、上一帧输出或累计速度。松回中心当次归零，反向按当前符号输出，不能为了“顺滑”引入历史拖尾。下游物理本身的加速/减速不属于该性质，分别检查曲线命令与真实速度。
8. 失焦、断开、暂停或控制权移交时，由输入归属层提交中性命令并丢弃过期采样；恢复时使用当前有效采样及当前配置，不重放旧杆量。非法样本输出中性并记诊断；非法曲线配置拒绝启用，回退到上一有效配置或保持相同校准/死区/最大速度的线性曲线，不移除安全死区。运行中改配置会直接改变同杆量输出，按项目声明在中立时提交或明确接受立即变化，不偷偷加入时间过渡。

## 调参与失败定位

先检查设备中心漂移与边缘覆盖，再调最小可靠死区，再调曲线形状，最后单独评估最大速度。死区越低不一定越好：既要抑制静置漂移，也要保留微动行程；不能用极小输出掩盖仍在累积的视角漂移。

- 中段仍过快：检查消费者是否丢了幅值、框架是否又套曲线；比较同杆量的各层输出后再调形状。
- 满杆变慢或斜向超速：检查 f 的端点、外缘校准、径向方向归一化与最大速度是否被一并改变。
- 起动有台阶：查死区是否只切零而未重铺剩余行程，或曲线/插值在端点不连续；先恢复连续线性基线。
- 反向发黏或恒定杆量越来越快：查时间滤波、历史速度及下游控制器；不要将它们混入无历史映射。
- 想加入玩家可调选项时，先确认项目需要并已有可安全应用的配置接口，再组合[交互状态反馈](../gameplay-contextual-ui/SKILL.md)；本任务本身不要求新增设置菜单、持久化或预设列表。

## 验收

- [ ] 中心、死区内、刚越死区、低/中/满杆逐段扫描：输出有限、连续、单调，零点为零、端点保留原最大命令。所选曲线的目标慢速区相比同死区的线性基线更细。
- [ ] 径向方案在四象限与斜向保留方向且长度不超约定范围；逐轴方案的方向变化和斜向上限符合已声明设计。轻推不会被消费者归一化成全速。
- [ ] 固定同一杆量，短按、长按及先前不同输入序列的映射结果一致；放回中心、即时反向无历史残留。不同采样率下同杆量结果一致，角速度积分另测帧率误差。
- [ ] 多个实际支持手柄静置不漂、边缘可达；断开、失焦、控制权切换及坏值不会继续使用旧命令。校准/死区只执行一次，失败回退不解除它们。
- [ ] 相机中段与近俯仰限位分别测试，记录限位层造成的差异；鼠标、键盘及 UI 导航保持既定行为。只改变曲线时，原最大速度、移动基和玩法碰撞规则不变。
- [ ] 在项目内实测细调目标、小幅行走和完整转身，记录取舍及未覆盖设备，不把数学性质或本库参考测试当作操控收益证明。

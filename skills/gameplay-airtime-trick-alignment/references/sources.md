## 去重与 owner 判断

完整解析基线 catalog 的 98 个 skill、全部 task_routes 与 sources 的 167 条记录，规范化所有非空 Instagram URL，并搜索完整 JSON 字段；本 ID、作者与 airtime/flight time/angular momentum 无既存命中。已有排除记录 DexAQsQh1WS 只展示跑车翻转/得分，没有实现机制，不能作为本机制的已存在 owner 或补算法依据。

选择一个独立的 `airtime-trick-alignment` owner，不是“动画类”大合并，也不为快速模式、预测失效或自由落体各建 owner。比较的边界如下：

- 本任务：由本次飞行和招式选择触发，读取有效剩余腾空与当前片段相位；推进空中计划→收束/回退→真实落地交接。失败验收是速率有界、预测失效不造落地、早晚接触可退出且原物理/输入意图不被改变。
- [动作相位](../../gameplay-action-timing/SKILL.md)：由输入后响应迟滞/重量问题触发，读取输入与生效时间轴，删减冗余准备或调整收势；验收保留规则时间和关键姿态，不消费飞行时间预测。
- [落地反馈](../../gameplay-landing-feedback/SKILL.md)：由真实着地边沿触发，读取接触强度，推进压缩/尘/镜头到复位；验收去重和同物理表现，不规划落地前翻转速度。
- [坏落地恢复](../../gameplay-landing-tumble-recovery/SKILL.md)：由明确授权的高速且坏角度接触触发，推进失控/掉物/恢复；验收真实玩法后果和安全恢复。本任务不能把预测误差变成该惩罚。
- [可变跳高](../../gameplay-variable-jump-height/SKILL.md)：由一次合法起跳后的按住/松开触发，改变上升速度或助力预算；验收高度可控且不增跳跃资格。它可能让原预测失效，但不是播放计划 owner。
- [相位重力](../../gameplay-asymmetric-jump-gravity/SKILL.md)：由升降/顶点运动相位触发，改加速度和下降上限；验收真实轨迹与积分正确。本任务读取其模型而不改写。
- [环境跳板](../../gameplay-launch-pad-feedback/SKILL.md)：由环境有效踩压与弹射确认触发，编排跳板、角色和镜头；飞行可作为本任务入口，但双翻转展示没有预测调速能力证据。
- [几何事件对齐](../../gameplay-geometric-event-alignment/SKILL.md)：由穿越工具空间边界触发，修权威离散事件的触发几何与一次性消费；验收切断早晚/漏判，不是围绕既有接触预测调动画。
- [预测步态](../../gameplay-gait-step-scheduling/SKILL.md)：由移动/转向意图与支撑脚状态触发，调度迈步和共享髋输出；验收选腿、滑步与并发贡献，不消费整次腾空时间。
- [移动接续](../../gameplay-traversal-transitions/SKILL.md)：由边缘/抓杆交互触发，改变停留/释放选择与控制恢复；验收自主意图和连续节奏，不把承诺时机或翻转速度同化成通用自动接续。
- [下冲转滚动量](../../gameplay-dash-roll-momentum/SKILL.md)：由下冲合格接地及后续冲刺输入触发，修改速度与储存预算；验收速度映射和有限链。本任务不负责动量转换或守恒求解。

因此登记独立路由和上述相邻边界；只在真正组合时复用其既有权威事件/模型，不移动现有 owner，也不把邻居来源挂到本技能冒充直接依据。

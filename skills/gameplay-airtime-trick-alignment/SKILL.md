# 腾空预测驱动的招式播放与接地衔接

## 触发与范围

已有跳跃/抛射与翻转动作，希望招式的可着地姿态接近预计接触时刻，而不是所有高度都用固定播放速度。输入为本次飞行的有效剩余时间预测、招式相位和玩家已选择的动作模式；输出为有限播放速率、空中等待/恢复姿态及真实接触后的状态交接。

只协调既有飞行与动作的时间关系，不构建完整弹道、碰撞、角动量、布娃娃或根运动控制器。普通接地尘/压缩走[落地反馈](../gameplay-landing-feedback/SKILL.md)；输入后多余准备段走[动作相位](../gameplay-action-timing/SKILL.md)。不能通过改重力、拉长腾空或瞬移根节点，使动画“看起来刚好落地”。

## 输入与前置条件

- 真实起飞/离地、合格落地、撞顶/侧撞、外力和模式切换事件；飞行 ID、角色生命周期代次及唯一运动权威。明确走落边缘、弹射或空中再跳是否允许本招式。
- 与实际移动模型一致的预测入口：从什么状态预测、采样时刻、剩余时间单位、预测有效范围、可能接触的表面/点、失效原因及更新策略。接地资格复用运动系统的定义，不把任意射线命中当落地。
- 招式片段及当前相位、目标接地前标记、允许播放速率区间、可混出的相位/姿态、空中中性姿态和已批准的异常出口。区分片段时间与仿真时间，约定入态混合期间相位是否前进。
- 动作选择与承诺时机、允许的空中输入、快速招式选项，以及独立自由落体/姿态控制模式的进入与退出规则。起飞前承诺只在项目明确采用时实施，不作为通用禁用空中输入的理由。
- 动画是否只写视觉骨骼，还是通过根运动、关节目标或其他路径影响真实轨迹。确认预测、动画与运动使用的时钟及暂停/时间缩放处理。

先检查项目现有接口。没有可用预测器时，可以接入已有的运动预演/预测结果，但必须先验证它覆盖当前重力、速度上限、输入和场景碰撞规则；不能临时套一个同高度抛体公式当通用预测。若预测无法与实际运动一致，保留原有播放与着地流程并报告缺少的依赖，不启用“自动对齐”。

## 实施顺序

### 1. 明确控制归属和一次飞行的动作状态

让运动系统继续拥有真实轨迹、接触与落地资格，动画系统只持有本次招式的播放计划。先记录固定速率基线：起飞、目标姿态达到、真实首次落地、当前速度与姿态。检查关闭招式时轨迹是否相同。

若调速会改变根运动、物理关节目标或真实旋转，先建立与运动权威一致的耦合契约；未完成前禁用这条调速路径，不默默关闭原根运动、增加力矩或把视觉旋转写入刚体。需要改变物理招式的任务单独实现和验证，本入口不接管。

状态至少区分：待起飞/待允许启动、空中招式、空中收束等待、真实落地交接、退出。为本次动作绑定飞行 ID/代次。起飞前选择只是意图，不创建成功起飞；收到许可的真实入口后才开始计划。同次重复事件不重播；新合法空中跳若受支持，明确结束旧计划后建立新飞行计划，不能借它刷新旧招式。

### 2. 为预测定义可用性，而不只取一个时间数

保存每个预测的采样仿真时刻、飞行 ID、运动模型/状态版本、候选接触对象及其有效性。一个可用结果必须同时满足：

- 时间有限且为正，位于预测器已验证的时间范围；候选接触满足项目落地资格，预测不是撞墙/撞顶时间。
- 状态与本次角色/飞行匹配，未超出项目允许的结果年龄；移动/旋转平台、重力、冲量、输入或几何变化未超过该预测器已声明的适用范围。
- 预测精度/稳定度满足所选动作所需容差。没有置信度字段时用已验证覆盖范围与误差测试界定可用性，不捏造一个可信分数。

若返回的是采样时刻的剩余秒数，先减去同一仿真时钟已经经过的时间；若是绝对预计接触时刻，直接减当前仿真时间。两种约定只能选一种，不能每帧重复扣减。负值、零、非有限数、无候选面、过期或超范围都走失效分支，不以最大搜索距离或无穷时间代替着地时间。

### 3. 用可行时间预算安排播放

在真实动作入口或允许重规划处，从当前相位到接地前目标标记取剩余片段时间 D。设当前有效预计剩余腾空为 T，项目希望目标姿态提前接触的准备时间为 L，则目标预算 B = T − L。D、T、L 必须有限，D 与 L 非负，并统一到声明的片段秒/仿真秒单位。

当 D > 0 且 B 超过项目的最小可调度时间时，可把 D / B 作为恒定播放速率候选，再限制到该片段允许的正值区间。实际混合若仍推进相位，就从混合后的当前相位重算 D；若入态阶段不推进，则先从 T 扣除该已知耗时，不能重复扣除。分段曲线也可使用，但必须保留同样的预算与边界检查。

限幅不是对齐成功：计算所选速率下实际到达标记的时间，记录与 B 的残差。过短飞行需要的速率超过上限时，选择项目已批准的短动作/无招式空中姿态或异常出口；过长飞行需要低于下限时，允许正常收束后进入中性空中姿态，或使用已有的等待段。不要冻结倒立姿势、倒放、无限减速或擅自增加翻转圈数。已承诺且不可取消的招式不能静默换招，必须使用其既定异常出口；未定义出口时先不启用该自动调速。

D 已为零时直接进入允许的空中收束等待，不用零速率锁住动画。B 非正、极短或预测无效时，不做除法、不用任意小数强行作分母，转入同样的明确回退。

### 4. 保留快速招式与独立模式的意图

普通对齐模式可以按预算调整播放；玩家明确选择快速完成的招式时，采用该模式既定速率/速度映射及上限，不为了填满长腾空把它拉慢。快速招式提前完成后进入其合法空中收束姿态，继续等待真实接触，不伪造落地。若快速选择本来改变实际起飞旋转/速度，预测必须读取运动系统已确认的结果；本流程不另施冲量或重定义其物理含义。

自由落体/直接姿态控制是另一模式，不是预测失败时自动开启的隐藏布娃娃。收到项目允许的模式切换后，撤销当前调速与待定回调，再通过现有控制权管理交接当前姿态/运动状态；不能让招式动画和姿态控制同时写同一通道。退出该模式后只按规则进入新的动作计划，不续播旧飞行残留。没有该模式的项目不因本技能新增它。

### 5. 预测变化时有界修订，不重启招式

为项目选择一种策略并记录适用范围：稳定飞行可锁定初始计划；变化较多且预测可靠时，可在规定更新时机从当前相位重规划。锁定计划也必须检查失效，不能继续把失效目标显示为可靠。

重规划采用当前 D 与新的 T，不重置相位、不重新触发起飞、不重放一次性动画事件。限制速率范围和变化斜率，避免每次预测抖动都突然加减速；若限幅或平滑使目标无法按期达到，记录不可行并执行回退，不谎报收束保证。更新策略不能突破玩家快速模式的既定速度规则。

撞顶、侧撞、外力、落点消失、重力/输入变化或平台运动超出模型时，使旧计划失效。由项目选择继续当前有界动作并转安全空中姿态，或混出到既有受撞/下落状态；重新得到有效预测只有在该状态仍允许重规划时才接回。不要等待预测恢复来阻止真实碰撞、也不默认新增翻倒、伤害或失控。

### 6. 真实接触优先，结束与回收只执行一次

每次更新先处理已确认的落地/中断结果，再推进仍有效的播放计划。预测倒计时到零、片段结束、到达目标标记都不是接地证据；未接触时继续合法空中收束/下落并使过期计划失效，不触发脚步尘、落地计分或接地重置。

真实落地早于目标标记时，立即交给既有落地/碰撞流程，取消旧速率目标并从当前姿态混入已批准的接地恢复。禁止为播完整个翻转而延迟碰撞、暂停空中、吸附到预测点或硬改刚体方向。若当前姿态没有可接受的恢复，采用项目明确的失败出口并暴露问题，不用强制“成功着陆”隐藏它。

真实落地晚于预测时，只保持允许的空中姿态；真实落地后的表现由[落地反馈](../gameplay-landing-feedback/SKILL.md)消费同一次权威边沿。需要坏落地惩罚时交给已有[翻倒恢复规则](../gameplay-landing-tumble-recovery/SKILL.md)，不从预测残差或翻转外观自动添加惩罚。

退出、死亡、传送、切场或角色复用时使计划代次失效，释放本层的速率覆盖、订阅和姿态权重；让当前状态重新给出播放设置，不盲目恢复进入时的全局动画速度。暂停时仿真预测与动作相位遵守同一时间约定，恢复后检查结果年龄；切换时间缩放不把墙钟间隔误作腾空已流逝时间。

## 调参顺序

1. 先测预测误差：固定输入与物理模型，记录预测采样、候选面、预计/实际接触时间和失效原因。预测超出容差时修预测接入或缩小支持范围，不能靠动画掩盖。
2. 再固定同一轨迹，标定接地前目标姿态、准备时间、各片段可读速率上下限与最短预算。对照固定速率和对齐速率，分别测姿态误差与物理轨迹。
3. 最后调重规划频率、速率变化限度、混出时间与中性空中等待。快速模式单独测，不能以填满所有腾空为验收目标。所有数值由项目动作与容差决定，不设通用速度倍率。

## 可观察验收与失败恢复

- [ ] 在支持的等高/高处/低处落地轨迹，记录飞行 ID、模式、预测版本/年龄、T、D、目标/实际速率、残差和真实落地相位。可行且预测有效时，目标姿态与实际接触的差距满足项目容差；动画调速前后物理轨迹与输入许可不变。
- [ ] 使用隔离的调度夹具检查候选计算：D=0.8 片段秒、T=1.0 仿真秒、L=0.2 仿真秒时未限幅候选为 1；这些仅为测试数据。再让所需速率超上限或低于下限，确认报告不可行/提前收束，不把 clamp 当成功。D=0 走收束；T=0、负值、非有限数及 B≤最小预算均不除零。
- [ ] 短跳、长落差、走落边缘与无可落地候选各走声明的支持/回退路径，不新增一次起跳或改变跳高。需要同高度假设的预测不能用于不同高度落点。
- [ ] 移动平台、斜坡、临时障碍、撞顶、外力及重力/输入变化按预测覆盖范围更新或失效；旧对象/旧飞行结果被丢弃，当前相位连续，速率不越界。
- [ ] 早接触立即停止旧计划并交接；预测到时但尚未接触不发落地事件；同帧多个接触/重复回调只结束一次。片段完成不重置跳跃许可、分数或落地资源。
- [ ] 快速招式在长飞行里仍按其速度选择完成，之后是合法空中等待；前置承诺与空中输入权限维持原设计。独立自由落体模式进入/退出无双重控制，也不被失败预测擅自启用。
- [ ] 取消、死亡、传送、重生、暂停、时间缩放与低渲染帧率后无旧速率覆盖、重复动画事件或旧预测回调；每次新飞行可以正常建立计划。

若姿态仍错位，按预测有效性→时钟/当前相位→预算与限幅→恢复混合顺序排查。若轨迹改变或控制器争写，立即退出本层调速，回到已有动作/运动设置，先解决动画与物理归属，不继续调倍率。

需要核对来源、作者设计及工程扩展边界时，读取[来源参考](references/sources.md)。

若项目另行采用[起跳水平动量修正](../gameplay-jump-horizontal-momentum/SKILL.md)，预测应读取该次真实修正后的运动状态，不能沿用改速前结果。已记录动作的插帧/seek 则走[骨架回放](../gameplay-rig-replay-interpolation/SKILL.md)，不在回看时重新跑本页飞行预测与招式计划。

# 手牌布局与卡牌选择

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 多张牌的布局、焦点、选中和离场效果混淆，或翻面时正反面不清。

## 先确认的输入

卡牌集合、顺序、焦点/选中状态、实际提交结果、显示层级和输入设备。

## 分步机制

1. 先把布局/悬停/选中/提交成功/移除列成显示状态，明确哪一步才改变实际游戏结果。
2. 按手牌数量比较扇形排列、阴影和跟随；放大/倾斜要让当前焦点可辨认，不遮住相邻可选牌。
3. 需要翻面时可采用缩窄→换图→展开，材质淡入只是可选表现；不把缩窄到零当实际卡牌数据已经换面。
4. 升级卡可用描边与倾斜说明焦点，橙色选中边框/烧蚀离场只是来源样式。实际选择已确认后再表现结果，取消和失败与成功区分。
5. 稀有卡奖励揭示只引用奖励流程；手牌交互不重复定义停顿、闪电或奖励结算。

## 适用限制

- 不按某种牌面美术另建机制 owner，排列/跟随与真实战斗规则分别验收。

## 验收

- [ ] 不同牌数、焦点快速切换、相邻遮挡和适用输入设备下选中对象唯一且可读。
- [ ] 翻面、取消、选中后移除和重复提交不残留错误牌面或重复应用结果。
- [ ] 关闭再开与重新排序后位置/层级正确；减少运动时仍辨认选择与结果。

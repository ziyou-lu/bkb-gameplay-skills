# 运行状态驱动的局部表面动画

## 触发与输入

用于机器运行但皮带纹理静止，或材质运动与真实状态矛盾。取得权威运行/转速、目标 renderer/子网格/材质槽、静止范围、UV 方向、每实例状态及停转/惯性契约。

## 实施流程

1. 同时记录机器状态和表面显示，区分无动画、信号错误、纹理不可辨或作用范围错误。
2. 将运动面与静态机架隔离，确认子网格/材质槽；给每台机器独立显示参数，避免修改共享资源时全部实例一起变速。
3. 在目标表面实现 UV 偏移，先用可辨纹理检查方向、接缝与重复；这是表面显示，不代表实体皮带绕轮运动。
4. 将权威转速映射为显示速度，再按选定时钟累积相位。映射函数、传动比与反向符号由项目定义；不让 UV 动画反过来写机器转速。
5. 处理启停、变速和项目支持的反向。零速是否立即静止取决于真实部件是否仍有惯性；绑定失效时停止或恢复到声明的静态状态。
6. 禁用重启、暂停恢复和销毁时清理实例参数与状态订阅，重新激活读取当前机器状态。

## 调参

先校准 UV 轴/符号与每周期位移，再调转速映射和相位连续性。高速纹理混叠时调整纹理特征或显示速度范围，不篡改真实 RPM；分别测低速可辨性和高速方向感。

## 验收与失败处理

- 停止、低/高转速、变速与支持的反向满足映射，静态机架不动。
- 同资源不同机器不串状态，接缝/重启无不可接受相位跳变。
- 状态源销毁不永久滚动，几何、碰撞、产能与实际转速不变。
- 误带动其他实例先查资源共享和绑定范围，不复制整个机器规则。

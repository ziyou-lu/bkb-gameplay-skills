本页仅供核对出处、参数来源和证据边界；不是执行入口。下列为改写前的研究记录，包含当时提出但未执行的迁移建议。当前实施步骤以 [SKILL.md](../SKILL.md) 为准；原始观察与验证状态以 [来源登记](../../../sources/posts.json) 为准。不得将历史建议、可见代码或作者说明当作已运行结果。

# 运行状态驱动的局部表面动画

本流程检查机器状态与显示是否一致。来源的 submesh / UV scroll / RPM 关联来自作者说明，编辑器只支持局部选面与绑定配置语境；没有独立测量最终滚动速度或执行展示代码。

## 触发条件

- 机械轮/发动机可见运行，但相邻皮带纹理不动，导致运行状态表达自相矛盾。
- 已有滚动材质不随机器启动、变速或停止更新，或误带动静止机架/其他实例。

## 先确认的输入

权威运行/转速信号、目标 renderer/子网格/材质槽、静止部分、UV 方向与可辨纹理、每台机器的独立状态。明确发动机 RPM 与所示表面的关系是否需要传动比/惯性等项目规则；来源未给比例和物理分工，显示不能反向成为机器物理状态。

## 分步机制

1. 记录机器真实状态与可见表面运动，区分没有动画、状态来源错误、纹理不可辨或误绑定。DXuFvaKjRl_ 作者说玩家注意到锯木厂皮带不动，不能把编辑投诉画面当新版收益测试。
2. 将需要运动的表面与静态机架隔离。来源实见 Submesh Isolation 标签、选中皮带面，以及 Unity 的 renderer/material index 配置；具体材质实例和运行时绑定方式未核，须在项目检查选择范围及共享资源影响。
3. 在目标表面建立可读的纹理运动候选。作者称使用 UV-scroll shader，但未公开完整代码、UV 布局或参数；先检查纹理方向、接缝与明显特征，不误称网格顶点或实体皮带真的绕轮移动。
4. 让表面动画读取已声明的机器状态，而不是与机器无关的固定时间滚动。作者以 engine RPM 同步为思路；速度曲线、比例、方向、相位累积和零速处理未知，不补成“线性比例已验证”或给通用系数。
5. 按项目约定检查启停、变速及支持的反向，处理对象禁用/重启和状态源失效。停止条件若由惯性或其他真实部件决定，应使用相符的状态契约，不用装饰动画假装机械仍在运行。
6. 分开验收状态一致性、作用范围与滚动可读性，再测成本。先保证静止机架和其他机器不受影响，再评价观感；没有测量就不宣称更沉浸、零延迟或性能改善。

## 来源与适用限制

- DXuFvaKjRl_ 的三部分流程为作者正文：子网格隔离、UV 滚动、与发动机 RPM 关联。实见第一层标题、选面和 Unity 材质索引/代码面板，后两层完整编号未核，不伪造逐层标签。
- 稀疏画面未独立建立最终 UV 运动与 RPM 的逐帧对应、数值速度比或零转速停下；展示代码未逐行审计或运行，不能当可直接移植脚本。
- 未核滚动方向/比例/曲线、相位重置、反转、UV 接缝、材质实例生命周期及不同机器共享材质行为。没有物理皮带、传动比求解、性能/沉浸感或音频验证。
- 本页只把已存在的运行规则表达为表面动画，不改变机器产能、碰撞、切断时机或实际转速；任意背景循环材质不因也使用 UV 而属于此任务。

## 验收

- [ ] 记录权威状态与显示输出，对照项目规定的停止、低/高转速和变速；满足所选映射，不默认线性比例或零速行为已在来源验证。
- [ ] 只目标皮带/表面移动，静态机架和使用同资源的其他机器实例不串状态；绑定/材质失效时按项目恢复或关闭显示。
- [ ] 纹理足够辨认方向和速度变化，接缝、重复、相位重置或反向时无不可接受跳变；若机器不支持反转，不自行加入真实反转规则。
- [ ] 暂停恢复、禁用/重启、切场和状态源销毁后显示与真实状态一致，无永久残留运动；惯性等项目条件另明示，不由动画擅造。
- [ ] 几何、碰撞、产能及 RPM 不因视觉映射意外变化，性能按目标平台测量；“看起来在动”不证明物理传动或沉浸收益。

## 组合而不复制

- [机关驱动](../../gameplay-mechanical-interactions/SKILL.md)涉及门体位移与可通行状态；本页改变局部表面显示，不让通行随 UV 变化。
- [事件形变](../../gameplay-motion-deformation/SKILL.md)在接触时改变形体，本页不复制形变回弹。
- [装饰跟随](../../gameplay-secondary-motion/SKILL.md)按父运动处理次级滞后，不替代权威转速到表面显示的关系。
- [几何事件对齐](../../gameplay-geometric-event-alignment/SKILL.md)决定切断等事件的边界；皮带动画不能证明切断判定正确。

# 切场遮蔽与就绪恢复

本文件是从来源案例提炼的迁移流程，不是作者源码复刻，也未在目标游戏中执行。下面的验收项是实施后要做的检查，不是已经通过的测试。

## 触发条件

- 卧室/走廊等场景切换突然显露未准备完的画面，或黑屏后不能恢复。

## 先确认的输入

目标场景、出生点/相机就绪条件、加载失败/取消路径、显示遮蔽状态以及项目输入恢复约定。

## 分步机制

1. 先重现并定位切场/出生点正确性问题；过渡遮蔽只解决显示跳变，不能替代根因修复。
2. 将遮蔽、切换/准备、恢复显示分开；是否需要淡出按项目决定，来源只实见黑屏后淡入。
3. 用项目真实就绪条件解除遮挡，不只等待固定动画时长。此为工程建议，原帖没有验证加载顺序。
4. 按项目决定是否锁输入；若锁定，正常完成和失败/取消都必须可恢复。处理中再次触发应遵循既定请求策略，不开启重叠切场。

## 适用限制

- 原帖外围字幕亮度不变支持游戏内淡入；穿过字幕的白竖线是视频剪辑，不算游戏实现。
- 没有完整淡出、曲线/时长、加载顺序或输入锁定证据；掩盖出生点闪动不证明修复 bug 或消除加载停顿。

## 验收

- [ ] 正常、慢加载、失败/取消下不会过早显露未就绪场景或永久黑屏。
- [ ] 关闭遮挡/调试检查时出生点与相机仍正确，不能把根因藏起来就验收。
- [ ] 反复进出、切换中再触发和持续按键不重复切场或遗留输入锁。

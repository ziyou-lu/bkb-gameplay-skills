# 道具突出部的接触覆盖与响应

## 触发与输入

用于树枝等突出部随主体移动却穿地，且确需真实接触。取得部件层级、局部形状/变换、质量与连接关系、允许分离条件、碰撞过滤和预算。装饰摆动不自动需要独立物理体。

## 实施流程

1. 用同一倒伏/侧撞场景同时显示可见轮廓与碰撞覆盖，区分无形状、形状错位与响应错误。不要放大主体形状填满枝间空隙。
2. 先选一个粗枝，可用项目支持的胶囊状长形碰撞几何作为候选，沿枝条轴对齐并调整长度、半径与局部偏移；验证缩放/旋转和地形接触后再扩到多枝。候选外形不限定具体 Collider API 或每枝独立刚体。
3. 按既定需求选主体复合碰撞或独立部件；后者需明确质量、连接自由度和自碰撞。只有需要分离时才接入项目破断条件，不从“有质量”直接推导可断关节。
4. 分开检查保持连接时响应和分离后自由响应；分离时解除旧约束与归属，不重复触发整物销毁或产物结算。
5. 增加部件前检查空隙通行、重复碰撞与成本，给分离件规定寿命/回收；细枝阻挡过多时收窄参与范围，不追求每片装饰物理化。

## 调参

先调形状覆盖和局部偏移，再调质量比、连接限制与接触材料；最后才调项目已有破断阈值。简化几何要保留关键碰触轮廓，不把树变为整面墙。

## 验收与失败处理

- 撞地/侧擦时指定部件接触正确，枝间空隙仍可通过。
- 未到分离条件保持关系，分离后不被拉回、不重复发奖励。
- 不同姿态、速度和数量无不可接受穿入、卡住/弹飞，成本与回收可控。
- 出现失稳回到单部件检查变换、质量和过滤，不先增大整体碰撞体。

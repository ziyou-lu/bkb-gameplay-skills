# 多阶段法术生命周期与形状层级

## 效果预览

每个阶段都是一团亮球；核心、尾迹、接触各有分工；表现辅助｜同一法术按真实阶段切换显示。

左侧为使用前，右侧为使用后；4 秒循环，用途示意（非引擎实测）。

![蓄力、飞行、命中，形状分清楚：使用前后对比](assets/before-after.webp)

## 触发条件

蓄力、释放、持续主体、接触与消散脱节，或持续法术像一团亮光。

## 输入与前置条件

各阶段真实事件、每次施法 ID、取消、危险区/伤害规则、对象归属与结束条件。

## 实施步骤

1. 列出本法术实际具有的 charge、release/core、travel/trail、impact/reaction 和 aftermath，缺少的阶段不强加；每次施法独立管理显示对象。
2. 将阶段切换绑定真实事件：蓄力取消不进入成功释放，未命中不伪造接触爆点；持续退出停止本次发射器。
3. 持续旋转主体先建立可追踪轮廓，区分核心与外围带。减少交错细线，检查多个循环相位下环绕带是否连续；配色按场景选择。
4. 线状冰刺可按主体排布、尺寸/扇形层次、地裂碎屑、终端簇与消散雾组织；光束类可选符文、压暗、多层光束、冲击环。只选当前法术需要的层，视觉形状不增加 AOE/冰冻/环境破坏。
5. 短停顿、镜头和冲击表现调用共享入口，优先保留下一招和真实危险区。
6. 区分规则结束和余效结束，持久地面痕迹独立管理；取消/切场按施法 ID 清理，不误删别的施法。

## 参数调整

先调主体宽度、核心/外围对比与旋转层级，再调粒子和亮度；逐层开关比较。余效寿命不控制伤害有效期，低特效需保留阶段辨识。

## 验收与失败处理

- [ ] 取消、释放、未命中、命中、持续退出与中断无旧层残留。
- [ ] 重复/多目标施法不串实例或重复结算，纯表现改动伤害时序不变。
- [ ] 多个循环相位、背景与低特效下主体/危险区仍可辨认。

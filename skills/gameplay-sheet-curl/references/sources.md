# 来源参考：玩法驱动的薄片卷曲

当前实施入口是 [SKILL.md](../SKILL.md)。本页区分作者机制、可见示例和工程迁移；不把建议公式或验收清单当作作者源码或已通过的测试。

## 归因与机制证据

- 来源：[DepIL1tPW6x](https://www.instagram.com/p/DepIL1tPW6x/)，作者 kennethchanny，Sticky Feet 开发者；观察日期 2026-10-23。
- 作者正文说明以顶点着色器处理纸张/薄布，不依赖骨骼蒙皮：在物体空间沿纸张长度归一化，顶端为 0、末端为 1；阈值前保持平直，超过阈值的部分映射到圆上，角度随越过阈值的距离变化。半径表示卷曲厚度/粗细，阈值可由玩法事件或系统驱动，并可添加正弦波飘动。
- 可见编辑器选中的蓝色薄片及起伏边缘、游戏场景墙上的“LIZARD DECOY”纸张与攀爬角色，以及卷成圆筒的纸张。画面支持网格形变及游戏场景用途，不证明碰撞同步或完整交互实现。

## 参数来源与未知项

- 长度坐标 0–1 与阈值 0.5 来自作者说明；0.5 是半段进入卷曲的示例，不是推荐默认值。依该分段方向，阈值越大，平直区越长。
- 半径具体值与单位、距离到角度的精确方程、顶点密度、飘动幅度/频率和交互动画时长未给出。
- 作者称省去不必要骨骼更高效；没有独立基准测试，不将此说法作为性能保证。
- 未捕获可执行代码或完整节点图，未运行源工程，音频未核听。来源不证明物理布料、自碰撞、多层有厚度卷绕或动态碰撞体。

## 工程迁移边界

执行入口中的正交基、θ = q/R 等弧长圆弧、厚度偏移法线与切向连续性是可选工程实现，不是作者提供的角度方程。正值半径、统一局部单位、原始顶点重建、实例隔离、状态反向/复用、飘动锚点权重、法线/阴影/bounds、缩放及无效输入检查均为实施与验收建议。它们需要在目标项目执行验证。

本机制的独立边界是“按长度阈值重映射薄片几何”：不是 UV 滚动，也不是角色整体 squash/stretch。来源登记见 [sources/posts.json](../../../sources/posts.json)。

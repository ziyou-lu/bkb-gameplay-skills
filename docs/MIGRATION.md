# 分类迁移说明

结构重整版本 eef0aca4 以 e537cd3 的全部 95 个主来源和 14 个入口为基线重审。来源没有新增、删除或升级证据等级；仅来源到技能的关联调整。技能数量由独立任务边界产生，不是目标，也不代表新增了同样数量的游戏实现。

判断看四件事：实际触发问题、所需输入、状态推进、关键失败验收。新作者/参数/风格留在原机制；不同控制规则、几何生成或异步状态不能只因同属“移动/界面/奖励”被合并。

| --- | --- |
| gameplay-hitstop | 保留统一时间强调。接触与非接触演出明确分支，但共享时钟归属、影响范围、叠加预算与恢复；不为每种触发复制时间管理，也不把揭示要求成命中。 |

| gameplay-camera-feedback | 只保留临时冲击/推近；速度映射另立持续速度镜头；完成镜头由完成事件流程持有。持续状态与控制权交接不是一次偏移归零。 |
| gameplay-motion-deformation | 保留短期形变/回弹/视觉后坐/smear；弹簧跟随、方向瞄准、动作相位和物理接触诊断分别迁出，因其输入与恢复/失败条件不同。 |

| gameplay-health-damage-ui | 收窄为持久 HP/损失残影；事件浮字与结果总分计数各自独立。伤害/治疗/得分浮字仍共享 owner，不按业务名复制动画。 |
| gameplay-melee-feedback | 保留普通命中/受击/暴击编排；剑刃采样网格、弹反、踩踏、受击恢复与攻击方向规则迁出。武器或作者不同不另立命中流程。 |
| gameplay-projectile-spells | 收窄为多阶段法术；射击/持续喷射与来源对齐另入口。冰刺、光束、火旋风仍共享生命周期分支，不按元素拆。 |
| gameplay-movement-feedback | 收窄为方向动画；冲刺、落地、离地宽限、移动交互停留/接续、转向辅助和接触表示各有入口。防误落与抓杆接续在同一状态决策入口保留相反策略，不混为必叠层。 |
| gameplay-breakables-loot | 保留破坏/死亡/采集到产物，木箱/桶/树是过程变体；奖励揭示与实际领取分离。宝箱/稀有卡/合并/升级仍共享表现绑定流程，业务状态按各项目独立，不宣称同一结算系统。 |

| gameplay-contextual-ui | 保留可用/焦点/按下/保持/真实提交，以及战斗菜单焦点。卡牌布局、对话进度、世界内投影、目标可见性、机关、连接、切场迁出，防止“都是 UI”掩盖独立失败路径。 |
| gameplay-skill-ingestion | 改为先比较用途/输入/状态/验收，再决定融合或新增；禁止无限扩大旧触发条件来维持固定数量。加入真实请求和相邻反例路由。 |

## 保真与兼容

- 全部 95 条原登记逐项比对：除 skill_ids 外，其余字段保持不变，包括观察、缺口、参数、署名、证据更新与未运行/未核听状态；92 条纳入来源仍都有 owner，3 条排除状态不变。逐来源新归属见[完整清单](../sources/INDEX.md)。
- 原 14 个 SKILL.md 路径全部保留；正文、description、输入、限制、验收与来源同步收窄，不只是另加一页却留下重复流程。
- 独立机制只有一个 owner；组合可关联同一来源，但只链接共享流程。结果计数、镜头移交与实际结算分开，不能因动画完成重复发放。
- 输入缓冲、Mercy Frames 标题和屏障材质以 evidence_only 路由保留证据缺口，不伪装完整能力。新增候选不混进这轮冻结来源。

## 防止再次退化

catalog.task_routes 为每个任务提供真实请求、主入口、机制、边界和 distinct_from 相邻任务。自动检查错误目标、重复 owner、证据说明冒充工作流、独立入口被重新合并；另做实际请求的独立人工/模型演练。前者不声称能判断所有自然语言，也不等于引擎/手感测试。
